## 技术实现

### 前端实现

**所有工具都是纯前端实现：**
- 使用React组件
- 使用浏览器API（localStorage、Web Speech API等）
- 使用CSS动画（3D效果）
- 不需要后端计算

### 数据收集实现

**使用统计API（简单）：**

```typescript
// 前端：调用统计API
const trackUsage = async (toolName: string) => {
  await fetch('/api/track-usage', {
    method: 'POST',
    body: JSON.stringify({ tool: toolName })
  })
}

// 后端：Next.js API Route
export async function POST(request: Request) {
  const { tool } = await request.json()
  
  // 保存到Supabase（简单统计）
  await supabase
    .from('usage_stats')
    .insert({ 
      tool_name: tool,
      created_at: new Date()
    })
  
  return Response.json({ success: true })
}
```

**数据库表（简化）：**

```sql
CREATE TABLE usage_stats (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_name VARCHAR(100) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_tool_name ON usage_stats(tool_name);
CREATE INDEX idx_created_at ON usage_stats(created_at);
```
