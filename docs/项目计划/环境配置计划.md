## 二、开发环境配置（dev）

### 2.1 本地 PostgreSQL 设置

**步骤：**

1. **安装 PostgreSQL**
   - Windows: 下载安装程序
   - macOS: `brew install postgresql@13`
   - Linux: `sudo apt install postgresql`

2. **启动 PostgreSQL 服务**
   - Windows: 在服务中启动 PostgreSQL
   - macOS: `brew services start postgresql@13`
   - Linux: `sudo systemctl start postgresql`

3. **创建数据库**
   ```sql
   CREATE DATABASE max_tool;
   ```

4. **执行SQL脚本**
   - 在 PostgreSQL 客户端执行
   - SQL脚本：`docs/上线资源/数据库设计-postgresql.sql`

5. **获取连接信息**
   - 主机：`localhost`
   - 端口：`5432`
   - 用户名：`postgres`（默认）
   - 密码：安装时设置的密码
   - 数据库：`max_tool`

---

### 2.2 本地环境变量配置

**文件：`.env.local`（不提交到Git）**

```env
# 环境标识
NODE_ENV=development

# 本地 PostgreSQL 连接信息
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your-password
DB_NAME=max_tool
```

---

### 2.3 安装 PostgreSQL 驱动

```bash
npm install pg @types/pg
```

## 四、数据库适配层

### 4.1 统一接口设计

**文件：`lib/database.ts`**

代码会自动检测连接方式：
- 如果提供了 `NEXT_PUBLIC_SUPABASE_URL` 和 `NEXT_PUBLIC_SUPABASE_ANON_KEY`，使用 Supabase 客户端
- 如果提供了 `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`，使用直接 PostgreSQL 连接
- 如果两者都提供，优先使用 Supabase

**统一接口：**
```typescript
// 插入使用统计
export async function insertUsageStats(toolName: string): Promise<void>

// 查询使用统计
export async function getUsageStats(toolName?: string)
```

**优势：**
- ✅ 应用代码无需关心连接方式
- ✅ 表结构统一，业务逻辑一致
- ✅ 通过环境变量自动切换连接方式

## 五、环境切换

### 5.1 自动检测

代码会自动检测环境变量，选择连接方式：

```typescript
// lib/database.ts
function detectConnectionType(): ConnectionType {
  // 优先使用 Supabase（如果提供了 URL 和 Key）
  if (process.env.NEXT_PUBLIC_SUPABASE_URL && process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY) {
    return 'supabase'
  }
  
  // 使用直接 PostgreSQL 连接（如果提供了连接信息）
  if (process.env.DB_HOST && process.env.DB_USER && process.env.DB_PASSWORD && process.env.DB_NAME) {
    return 'postgresql'
  }
  
  throw new Error('Missing database configuration')
}
```

## 十、API适配

### 10.1 统一API接口

**文件：`app/api/track-usage/route.ts`**

```typescript
import { NextResponse } from 'next/server'
import { insertUsageStats } from '@/lib/database'
import { validateToolName } from '@/lib/validation'

export async function POST(request: Request) {
  try {
    const { tool } = await request.json()
    
    // 验证
    if (!tool || typeof tool !== 'string') {
      return NextResponse.json(
        { success: false, error: 'Invalid tool name' },
        { status: 400 }
      )
    }
    
    if (!validateToolName(tool)) {
      return NextResponse.json(
        { success: false, error: 'Invalid tool name' },
        { status: 400 }
      )
    }
    
    // 插入数据（自动适配 Supabase 或直接 PostgreSQL 连接）
    await insertUsageStats(tool)
    
    return NextResponse.json({ success: true })
  } catch (error) {
    console.error('API error:', error)
    return NextResponse.json(
      { success: false, error: 'Internal server error' },
      { status: 500 }
    )
  }
}
```
