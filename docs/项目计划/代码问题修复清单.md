## 二、需要修复的问题 ⚠️

### 2.1 统计调用时机优化

**问题：**
- 当前所有工具在组件挂载时（useEffect）调用统计
- 应该在实际使用时调用（如用户点击按钮）

**影响：**
- 用户只是访问页面就会统计，不是实际使用
- 可能导致统计数据不准确

**建议修复：**
```typescript
// 当前（DrawLots.tsx）
useEffect(() => {
  trackUsage('draw-lots')
}, [])

// 建议改为
const handleDraw = () => {
  // ... 抽签逻辑
  trackUsage('draw-lots') // 在实际使用时调用
}
```

**需要修改的工具：**
- 所有20个工具都需要调整统计调用时机
