**你的项目已经在用 Tailwind CSS v4**，所以**最推荐：方案 B - Tailwind v4 @theme + CSS 变量**

**核心优势：**

## 一、方案概览

### 方案一：纯 CSS Variables

```css
/* globals.css */
:root {
  --bg-primary: #ffffff;
  --text-primary: #171717;
}
.dark {
  --bg-primary: #0a0a0a;
  --text-primary: #ededed;
}
```

```tsx
// 组件中
<div style={{ background: 'var(--bg-primary)', color: 'var(--text-primary)' }}>
  Content
</div>
```

### 方案二：Tailwind Dark Mode（当前方案）

```tsx
// 组件中
<div className="bg-white dark:bg-gray-800 text-gray-900 dark:text-gray-100">
  Content
</div>
```

### 方案三：CSS-in-JS 主题系统

```tsx
// styled-components 示例
const Card = styled.div`
  background: ${props => props.theme.bg};
  color: ${props => props.theme.text};
`
```

### 方案四：Tailwind v4 @theme + CSS 变量 ⭐️ 推荐

```css
/* globals.css */
@theme {
  --color-bg-card: #ffffff;
  --color-text-primary: #171717;
}

@layer theme {
  .dark {
    --color-bg-card: #1e293b;
    --color-text-primary: #f8fafc;
  }
}
```

```tsx
// 组件中
<div className="bg-bg-card text-text-primary">
  Content
</div>
```

## 二、扩展性分析（核心对比）

### 场景 1：增加 1 种新主题模式（如：高对比度主题、炫彩主题）

#### 方案一：纯 CSS Variables

**工作量：** ⭐⭐⭐⭐⭐ 简单

```css
/* globals.css - 只需添加新主题 */
:root {
  --bg-primary: #ffffff;
  --text-primary: #171717;
}

.dark {
  --bg-primary: #0a0a0a;
  --text-primary: #ededed;
}

/* 新增高对比度主题 */
.high-contrast {
  --bg-primary: #000000;
  --text-primary: #ffffff;
}
```

**优势：**
- ✅ 只需在 `globals.css` 添加新主题变量
- ✅ 所有组件自动支持新主题（因为用的是 CSS 变量）
- ✅ 无需修改任何组件代码

**劣势：**
- ❌ 不能用 Tailwind 工具类
- ❌ 需要用 `style` 属性或自定义 CSS

---

#### 方案二：Tailwind Dark Mode

**工作量：** ⚠️ ⭐⭐ 困难

```tsx
// 每个组件都需要添加新主题的样式
<div className="
  bg-white dark:bg-gray-800 high-contrast:bg-black
  text-gray-900 dark:text-gray-100 high-contrast:text-white
">
  Content
</div>
```

**优势：**
- ✅ 可以用 Tailwind 工具类

**劣势：**
- ❌ **需要修改所有组件**（20+ 个工具组件 × 3 个主题 = 60+ 处修改）
- ❌ **容易遗漏**，忘记添加新主题样式
- ❌ **维护成本极高**，每次新增主题都要改所有组件

---

#### 方案三：CSS-in-JS

**工作量：** ⭐⭐⭐⭐ 中等

```tsx

  light: { bg: '#ffffff', text: '#171717' },
  dark: { bg: '#0a0a0a', text: '#ededed' },
  highContrast: { bg: '#000000', text: '#ffffff' } // 新增
}
```

**优势：**
- ✅ 类型安全
- ✅ 组件自动支持新主题

**劣势：**
- ❌ 需要引入额外库
- ❌ 与 Tailwind 不兼容
- ❌ 运行时性能开销

## 四、具体实现（方案四 - 推荐方案）

### 第 1 步：定义主题变量

```css
/* globals.css */
@import "tailwindcss";

/* 基础主题变量 */
@theme {
  /* 背景色 */
  --color-bg-primary: #ffffff;
  --color-bg-secondary: #f5f5f5;
  --color-bg-card: #ffffff;
  
  /* 文字色 */
  --color-text-primary: #171717;
  --color-text-secondary: #666666;
  --color-text-muted: #999999;
  
  /* 边框色 */
  --color-border: #e5e5e5;
  
  /* 强调色 */
  --color-accent: #3b82f6; /* blue-500 */
}

/* Dark 模式 */
@layer theme {
  .dark {
    --color-bg-primary: #0f172a;    /* slate-900 */
    --color-bg-secondary: #1e293b;  /* slate-800 */
    --color-bg-card: #1e293b;       /* slate-800 */
    
    --color-text-primary: #f8fafc;  /* slate-50 */
    --color-text-secondary: #cbd5e1; /* slate-300 */
    --color-text-muted: #94a3b8;    /* slate-400 */
    
    --color-border: #334155;        /* slate-700 */
    
    --color-accent: #60a5fa;        /* blue-400 */
  }
  
  /* 高对比度主题（示例） */
  .high-contrast {
    --color-bg-primary: #000000;
    --color-bg-card: #000000;
    --color-text-primary: #ffffff;
    --color-text-secondary: #ffffff;
    --color-border: #ffffff;
    --color-accent: #ffff00;
  }
}
```

### 第 2 步：组件中使用

```tsx
// 组件中 - 无需写 dark: 前缀
<div className="bg-bg-card text-text-primary border border-border">
  <h3 className="text-text-primary">Title</h3>
  <p className="text-text-secondary">Content</p>
</div>
```

### 第 3 步：切换主题

```tsx
// ThemeProvider.tsx - 无需修改
document.documentElement.classList.toggle('dark');
// 或
document.documentElement.classList.toggle('high-contrast');
```
