# 主题方案选择 - 最终确认

## 方案对比（简洁版）

| 方案 | 是否需要写 dark: | 增加新主题 | 增加新工具 | 迁移成本 | 推荐度 |
|------|-----------------|-----------|-----------|---------|--------|
| **方案 A：Tailwind Dark Mode（当前）** | ✅ 需要 | ❌ 需改所有组件 | ❌ 每个都要写 dark: | - | ⭐⭐ |
| **方案 B：Tailwind v4 @theme + CSS 变量** | ❌ 不需要 | ✅ 只需改 1 个文件 | ✅ 自动支持 | ⭐⭐⭐ 中 | ⭐⭐⭐⭐⭐ |

---

## 推荐：方案 B（Tailwind v4 @theme + CSS 变量）

### 理由

1. ✅ **你的项目已经在用 Tailwind v4**（`package.json` 中已有）
2. ✅ **不需要写 `dark:` 前缀**（代码更简洁）
3. ✅ **扩展性强**（增加新主题只需改 1 个文件）
4. ✅ **新增工具自动支持**（无需额外工作）

### 迁移成本

- **需要修改：** `globals.css` + 逐步迁移现有组件
- **工作量：** 中等（可以逐步迁移，不影响现有功能）
- **收益：** 高（长期维护成本大幅降低）

---

## 具体实现（方案 B）

### 第 1 步：更新 `globals.css`

```css
@import "tailwindcss";

@theme {
  --color-bg-primary: #ffffff;
  --color-bg-card: #ffffff;
  --color-text-primary: #171717;
  --color-text-secondary: #666666;
  --color-border: #e5e5e5;
  --color-accent: #3b82f6;
}

@layer theme {
  .dark {
    --color-bg-primary: #0f172a;
    --color-bg-card: #1e293b;
    --color-text-primary: #f8fafc;
    --color-text-secondary: #cbd5e1;
    --color-border: #334155;
    --color-accent: #60a5fa;
  }
}
```

### 第 2 步：组件中使用

```tsx
// 之前（需要写 dark:）
<div className="bg-white dark:bg-gray-800 text-gray-900 dark:text-gray-100">

// 之后（不需要写 dark:）
<div className="bg-bg-card text-text-primary">
```

## 决策建议

### ✅ 选择方案 B，如果：
- 希望代码更简洁（不需要写 `dark:` 前缀）
- 计划增加新主题（如高对比度主题）
- 计划快速扩展工具（20+ 个新工具）
- 愿意投入中等迁移成本

### ⚠️ 保持方案 A，如果：
- 现有组件不多（< 10 个）
- 不计划增加新主题
- 不想迁移现有代码

---

## 下一步

**如果选择方案 B：**
1. 更新 `globals.css` 定义主题变量
2. 逐步迁移现有组件（可以分批进行）
3. 新组件使用主题变量

**如果保持方案 A：**
- 继续使用 `dark:` 前缀
- 新增工具时记得添加 dark 样式

---

## 一句话总结

**推荐方案 B**：Tailwind v4 @theme + CSS 变量，**不需要写 `dark:` 前缀，扩展性强，适合你的项目**。
