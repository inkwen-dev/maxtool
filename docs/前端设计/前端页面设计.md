# 前端页面设计（简版）

## 设计风格定位

**目标风格：** 简洁、现代、易用（参考国外工具网站）  
**设计原则：** 简洁优先，功能清晰，快速加载

## 二、颜色方案

### 2.1 主色调

**背景色：**
- 主背景：`#FFFFFF`（白色）
- 次要背景：`#F9FAFB`（浅灰）

**主色：**
- 主色：`#3B82F6`（蓝色，专业、可信）
- 主色hover：`#2563EB`（深蓝）
- 强调色：`#10B981`（绿色，成功）

**文字色：**
- 主文字：`#111827`（深灰黑）
- 次要文字：`#6B7280`（中灰）
- 辅助文字：`#9CA3AF`（浅灰）

**边框色：**
- 边框：`#E5E7EB`（浅灰）

---

## 三、字体方案

### 3.1 字体选择

**英文字体：**
- 主字体：`Inter` 或 `System UI`（现代、易读）
- 代码字体：`Monaco` 或 `Courier New`（等宽）

**字体大小：**
- 大标题：`2.5rem` (40px)
- 标题：`1.875rem` (30px)
- 副标题：`1.25rem` (20px)
- 正文：`1rem` (16px)
- 小字：`0.875rem` (14px)

  /* 2列布局 */

/* 桌面 */
@media (min-width: 1025px) {
  /* 4列布局 */

## 七、设计要点总结

### 7.1 国外用户喜欢的风格

**简洁：**
- ✅ 大量留白
- ✅ 清晰的层次
- ✅ 减少视觉噪音

**现代：**
- ✅ 圆角设计
- ✅ 柔和的阴影
- ✅ 平滑的过渡动画

**易用：**
- ✅ 清晰的导航
- ✅ 大号按钮
- ✅ 明确的反馈

**专业：**
- ✅ 统一的配色
- ✅ 一致的间距
- ✅ 清晰的字体

---

### 7.2 设计原则

1. **简洁优先**：减少不必要的元素
2. **功能清晰**：每个元素都有明确目的
3. **快速加载**：优化图片和资源
4. **响应式**：适配所有设备
5. **易用性**：降低学习成本
