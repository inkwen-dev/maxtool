# 工具信息维护方案

## 🎯 你的核心意图分析

### 核心问题
**"快速看清楚哪些人、什么场景使用什么工具，用的多不多"**

### 真实意图
1. **产品规划视角**：理解每个工具的产品定位
2. **用户画像**：知道目标用户是谁
3. **使用场景**：知道在什么情况下使用
4. **价值评估**：预估使用频次，判断工具价值
5. **决策支持**：基于这些信息做产品决策（优先级、是否开发等）

---

## 📋 建议维护的信息维度

### 1. 使用人群（目标用户）
**目的**：明确工具的目标用户群体

**格式示例：**
```markdown
**使用人群：**
- 活动组织者（主要用户，80%）
- HR人员（次要用户，15%）
- 普通用户（偶尔使用，5%）
```

**价值**：帮助理解工具的市场定位，指导产品设计和推广策略

---

### 2. 使用场景（具体场景）
**目的**：详细描述在什么情况下使用这个工具

**格式示例：**
```markdown
**使用场景：**
- 年会抽奖：公司年会需要从员工名单中随机抽取获奖者（高频场景）
- 活动抽奖：活动需要公平抽取参与者（中频场景）
- 决定谁来做某事：3个人不知道谁来干活，用抽签决定（低频场景）
```

**价值**：帮助理解工具的实际应用场景，指导功能设计

---

### 3. 使用频次（预估）
**目的**：预估工具的使用频率，判断工具价值

**格式示例：**
```markdown
**使用频次：** ⭐⭐⭐⭐⭐ (高频)
- 年会抽奖：高频（每年12月-1月集中使用）
- 活动抽奖：中频（全年持续使用）
- 团队分配：低频（偶尔使用）
```

**价值**：帮助判断工具优先级，决定资源投入

---

### 4. 工具价值（为什么有用）
**目的**：说明工具的核心价值

**格式示例：**
```markdown
**工具价值：** 公平透明，支持多轮抽奖，适合活动抽奖、团队分配等场景，避免人工选择的主观性。
```

**价值**：帮助理解工具的核心竞争力

---

### 5. 市场定位（可选）
**目的**：工具在市场中的定位

**格式示例：**
```markdown
**市场定位：** 活动组织工具，面向B端和C端用户
```

**价值**：帮助理解工具的商业价值

---

### 6. 优先级（可选）
**目的**：工具的开发/维护优先级

**格式示例：**
```markdown
**优先级：** P0（核心工具，必须维护）
```

**价值**：帮助资源分配决策

## 💡 维护建议

### 信息维护原则
1. **使用人群**：基于产品理解，预估主要用户群体
2. **使用场景**：详细描述具体使用场景，越具体越好
3. **使用频次**：基于场景预估，不是实际数据
4. **工具价值**：一句话说明核心价值
5. **定期更新**：随着产品理解加深，定期更新信息

### 维护流程
1. **初始创建**：基于产品理解填写预估信息
2. **定期回顾**：每月回顾一次，根据实际情况调整
3. **决策支持**：基于这些信息做产品决策

---

## ❓ 需要确认的信息

1. **信息详细程度**：是否需要维护"市场定位"和"优先级"？
2. **使用人群格式**：是否需要百分比，还是只需要列出人群？
3. **使用场景格式**：是否需要标注"高频/中频/低频"？
4. **汇总页面**：需要哪些汇总视图？（按人群、按场景、按频次）
