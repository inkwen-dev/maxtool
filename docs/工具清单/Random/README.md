# 🎲 Random（随机工具类）

**工具数量：** 7 个  
**分类说明：** 随机选择、抽奖、分配、决策类工具

---

## 工具列表

### 🎲 Draw Lots（抽签工具）

**使用人群：**
- 活动组织者（主要用户，80%）
- HR人员（次要用户，15%）
- 普通用户（偶尔使用，5%）

**使用场景：**
- 年会抽奖：公司年会需要从员工名单中随机抽取获奖者（高频场景，每年12月-1月集中使用）
- 活动抽奖：活动需要公平抽取参与者（中频场景，全年持续使用）
- 决定谁来做某事：3个人不知道谁来干活，用抽签决定（低频场景，偶尔使用）
- 多轮抽奖：需要连续抽取多个获奖者，已中奖者不重复参与（中频场景）

**使用频次：** ⭐⭐⭐⭐⭐ (高频)
- 年会抽奖：高频（每年12月-1月集中使用）
- 活动抽奖：中频（全年持续使用）
- 团队分配：低频（偶尔使用）

**工具价值：** 公平透明，支持多轮抽奖，适合活动抽奖、团队分配等场景，避免人工选择的主观性。

### 🔢 Random Number Generator（随机数生成器）

**使用人群：**
- 游戏玩家（主要用户，50%）
- 普通用户（次要用户，40%）
- 开发者（偶尔使用，10%）

**使用场景：**
- 游戏随机数：需要生成指定范围内的随机数字（中频场景）
- 抽奖编号：从1-1000中随机抽取一个编号（低频场景）
- 测试数据：生成测试用的随机数值（低频场景）
- 决策辅助：不知道选哪个数字时，随机生成（中频场景）

**使用频次：** ⭐⭐⭐ (中频)
- 游戏随机数：中频（游戏时使用）
- 决策辅助：中频（需要随机数字时使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 快速生成指定范围的随机数，支持自定义范围，适合各种需要随机数字的场景。

### 🪙 Flip Coin（抛硬币）

**使用人群：**
- 普通用户（主要用户，70%）
- 游戏玩家（次要用户，25%）
- 活动组织者（偶尔使用，5%）

**使用场景：**
- 快速决策：两个人不知道谁先来，抛硬币决定（中频场景）
- 游戏比大小：3个人不知道谁来干活，用抛硬币比正反面（中频场景）
- 简单选择：二选一的快速决策方式（中频场景）
- 公平选择：需要完全随机的二选一结果（低频场景）

**使用频次：** ⭐⭐⭐ (中频)
- 快速决策：中频（需要二选一时使用）
- 游戏比大小：中频（游戏时使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 最简单的随机决策工具，3D动画效果，适合快速二选一决策场景。

### 🎡 Roulette（轮盘选择器）

**使用人群：**
- 普通用户（主要用户，60%）
- 活动组织者（次要用户，30%）
- 游戏玩家（偶尔使用，10%）

**使用场景：**

**使用频次：** ⭐⭐⭐ (中频)
- 快速随机选择：中频（需要从多个选项选择时使用）
- 决定吃什么：中频（日常使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 支持批量导入选项，动画效果，适合快速从多个选项中随机选择的场景。
