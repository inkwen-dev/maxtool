## 工具列表

### 🔤 Font Generator（字体生成器）

**使用人群：**
- 社交媒体用户（主要用户，50%）
- 内容创作者（次要用户，35%）
- 普通用户（偶尔使用，15%）

**使用场景：**
- 创意字体：需要生成各种创意字体样式（中频场景）
- 文本美化：需要美化文本显示效果（中频场景）
- 社交媒体：需要在社交媒体上使用特殊字体（中频场景）
- 文档装饰：需要在文档中使用特殊字体效果（低频场景）

**使用频次：** ⭐⭐⭐ (中频)
- 创意字体：中频（需要美化文本时使用）
- 文本美化：中频（需要美化文本时使用）
- 社交媒体：中频（社交媒体发布时使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 支持多种字体样式，一键生成，适合需要文本美化和创意字体的场景。

### 📱 Instagram Fonts（Instagram字体）

**使用人群：**
- 社交媒体用户（主要用户，80%）
- 内容创作者（次要用户，15%）
- 普通用户（偶尔使用，5%）

**使用场景：**
- Instagram美化：需要在Instagram个人简介、帖子中使用特殊字体（高频场景，持续使用）
- 社交媒体：需要在社交媒体上使用吸引眼球的字体（高频场景，持续使用）
- 个人品牌：需要个性化的字体来展示个人品牌（中频场景）
- 内容创作：需要为内容创作添加特殊字体效果（中频场景）

**使用频次：** ⭐⭐⭐⭐ (高频)
- Instagram美化：高频（社交媒体发布时持续使用）
- 社交媒体：高频（社交媒体发布时持续使用）
- 个人品牌：中频（偶尔使用）
- 内容创作：中频（偶尔使用）

**工具价值：** 专为Instagram等社交媒体设计，支持多种字体样式，适合社交媒体美化场景。

### 🔊 Text to Speech（文本转语音）

**使用人群：**
- 学生（主要用户，40%）
- 上班族（次要用户，35%）
- 视力不便用户（偶尔使用，25%）

**使用场景：**
- 语音朗读：需要将文本转换为语音朗读出来（中频场景）
- 学习辅助：需要听文本内容，比如学习外语（中频场景）
- 无障碍访问：视力不便的用户需要语音朗读（低频场景）
- 多任务处理：需要边做其他事情边听文本内容（中频场景）

**使用频次：** ⭐⭐ (低频)
- 语音朗读：中频（需要听文本时使用）
- 学习辅助：中频（学习时使用）
- 多任务处理：中频（需要多任务时使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 支持自定义语速、音调、音量，适合需要语音朗读的各种场景。
