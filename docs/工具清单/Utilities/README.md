## 工具列表

### 🔢 Counter（计数器）

**使用人群：**
- 活动组织者（主要用户，40%）
- 普通用户（次要用户，40%）
- 游戏玩家（偶尔使用，20%）

**使用场景：**
- 人数统计：需要统计人数，比如活动签到人数（中频场景）
- 点击计数：需要记录点击次数，比如鼠标点击测试（低频场景）
- 分数统计：需要记录分数，比如游戏得分（中频场景）
- 数量统计：需要统计任何可计数的项目（中频场景）

**使用频次：** ⭐⭐⭐ (中频)
- 人数统计：中频（活动组织时使用）
- 分数统计：中频（游戏时使用）
- 数量统计：中频（需要计数时使用）
- 其他场景：低频（偶尔使用）

**工具价值：** 简单易用，支持自定义步长，适合各种需要计数的场景。
