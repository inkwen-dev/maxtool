# 开发环境配置指南

## 🎯 目标

配置本地开发环境，使用本地 PostgreSQL 数据库进行开发调试。

---

## 📋 前置准备

### 1. 检查项目结构

确保项目已安装依赖：

```bash
cd maxtool
npm install
```

### 2. 确认已安装的包

项目需要以下依赖（应该已在 `package.json` 中）：
- `pg` - PostgreSQL 客户端（本地连接）
- `@supabase/supabase-js` - Supabase 客户端（生产环境用）

---

## 🚀 配置步骤（详细版）

### 步骤 1：安装 PostgreSQL

#### Windows

1. **下载 PostgreSQL**
   - 访问 [PostgreSQL 官网](https://www.postgresql.org/download/windows/)
   - 下载 PostgreSQL 安装程序
   - 推荐版本：PostgreSQL 13 或更高版本

2. **安装 PostgreSQL**
   - 运行安装程序
   - 设置 postgres 用户密码（记住这个密码！）
   - 端口使用默认的 5432
   - 完成安装

3. **验证安装**
   - 打开命令提示符或 PowerShell
   - 运行：`psql --version`
   - 应该显示 PostgreSQL 版本号

#### macOS

```bash
# 使用 Homebrew 安装
brew install postgresql@13

# 启动 PostgreSQL 服务
brew services start postgresql@13
```

#### Linux (Ubuntu/Debian)

```bash
# 安装 PostgreSQL
sudo apt update
sudo apt install postgresql postgresql-contrib

# 启动 PostgreSQL 服务
sudo systemctl start postgresql
sudo systemctl enable postgresql
```

---

### 步骤 2：创建数据库

#### 2.1 连接到 PostgreSQL

**Windows (使用 psql)：**
```powershell
# 打开命令提示符或 PowerShell
psql -U postgres
# 输入密码（安装时设置的密码）
```

**macOS/Linux：**
```bash
sudo -u postgres psql
```

#### 2.2 创建数据库

```sql
-- 创建数据库
CREATE DATABASE max_tool;

-- 验证数据库创建
\l
```

**退出 psql：**
```sql
\q
```

---

### 步骤 3：执行 SQL 脚本创建表

#### 3.1 获取 SQL 脚本

SQL 脚本在：`docs/上线资源/数据库设计-postgresql.sql`

#### 3.2 执行 SQL 脚本

**方法 1：使用 psql 命令行**

```bash
# Windows PowerShell
psql -U postgres -d max_tool -f docs/上线资源/数据库设计-postgresql.sql

# macOS/Linux
psql -U postgres -d max_tool -f docs/上线资源/数据库设计-postgresql.sql
```

**方法 2：使用 PostgreSQL 客户端工具**

如果你有 PostgreSQL 客户端工具（如 pgAdmin、DBeaver、DataGrip），可以：
1. 连接到本地 PostgreSQL
2. 选择 `max_tool` 数据库
3. 打开 SQL 脚本文件
4. 执行脚本

**方法 3：在 psql 中执行**

```bash
# 连接到数据库
psql -U postgres -d max_tool

# 复制 SQL 脚本内容并粘贴执行
```

#### 3.3 验证表创建

```sql
-- 查看所有表
\dt

-- 查看表结构
\d usage_stats
```

应该能看到 `usage_stats` 表。

---

### 步骤 4：创建环境变量文件

在项目根目录创建 `.env.local` 文件：

**Windows PowerShell：**
```powershell
cd maxtool
Copy-Item env.example .env.local
```

**或手动创建：**
1. 在项目根目录下创建新文件
2. 命名为 `.env.local`

**文件位置：** `maxtool/.env.local`

---

### 步骤 5：配置环境变量

编辑 `.env.local` 文件，添加以下内容：

```env
# ============================================
# 开发环境配置（本地 PostgreSQL）
# ============================================

# 环境标识
NODE_ENV=development

# 本地 PostgreSQL 连接信息
# 请替换为你的实际连接信息
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your-postgres-password
DB_NAME=max_tool
```

**重要：** 将以下值替换为你的实际信息：
- `your-postgres-password` → 你安装 PostgreSQL 时设置的密码
- `max_tool` → 数据库名称（如果不同，请修改）

---

### 步骤 6：测试数据库连接

#### 6.1 启动开发服务器

```bash
cd maxtool
npm run dev
```

**预期输出：**
```
  ▲ Next.js 16.0.6
  - Local:        http://localhost:3002
  - Ready in 2.3s
  ✅ PostgreSQL pool initialized
```

**如果看到 `✅ PostgreSQL pool initialized`，说明数据库连接成功！**

#### 6.2 测试工具使用统计

1. **打开浏览器**
   - 访问 http://localhost:3002

2. **使用工具**
   - 点击任意工具（如 Draw Lots）
   - 使用工具功能

3. **检查数据库记录**
   - 在 psql 或 PostgreSQL 客户端执行：
   ```sql
   SELECT * FROM usage_stats ORDER BY created_at DESC LIMIT 10;
   ```

**如果能看到记录，说明配置成功！**

## 🔧 常见问题排查

### 问题 1：连接失败 "ECONNREFUSED"

**错误信息：**
```
Error: connect ECONNREFUSED 127.0.0.1:5432
```

**原因：** PostgreSQL 服务未启动

**解决步骤：**
1. **Windows：**
   - 打开"服务"（services.msc）
   - 找到 "postgresql-x64-13" 服务
   - 右键 → 启动

2. **macOS：**
   ```bash
   brew services start postgresql@13
   ```

3. **Linux：**
   ```bash
   sudo systemctl start postgresql
   ```

---

### 问题 2：连接失败 "password authentication failed"

**错误信息：**
```
Error: password authentication failed for user "postgres"
```

**原因：** 密码错误

**解决步骤：**
1. 检查 `.env.local` 中的 `DB_PASSWORD`
2. 确认密码是否正确
3. 如果忘记密码，可以重置：
   - Windows：在服务中重启 PostgreSQL，或使用 pgAdmin 重置
   - macOS/Linux：使用 `sudo -u postgres psql` 重置密码

---

### 问题 3：找不到数据库 "database does not exist"

**错误信息：**
```
Error: database "max_tool" does not exist
```

**原因：** 数据库未创建

**解决步骤：**
1. 执行步骤 2 创建数据库
2. 确认 `.env.local` 中的 `DB_NAME` 正确
3. 检查数据库名称拼写

---

### 问题 4：表不存在 "relation does not exist"

**错误信息：**
```
Error: relation "usage_stats" does not exist
```

**原因：** 未执行 SQL 脚本创建表

**解决步骤：**
1. 执行步骤 3 的 SQL 脚本
2. 确认表已创建：`\dt` 或 `SELECT * FROM information_schema.tables WHERE table_name = 'usage_stats';`
3. 检查是否选择了正确的数据库

---

### 问题 5：环境变量未生效

**现象：** 修改 `.env.local` 后，配置未生效

**原因：** Next.js 需要重启才能读取新的环境变量

**解决步骤：**
1. 停止开发服务器（Ctrl+C）
2. 重新启动：`npm run dev`
3. 检查控制台输出，确认看到 "✅ PostgreSQL pool initialized"

---

### 问题 6：端口被占用

**错误信息：**
```
Error: listen EADDRINUSE: address already in use :::3002
```

**原因：** 端口 3002 已被占用

**解决步骤：**
1. 关闭占用端口的程序
2. 或修改 `package.json` 中的端口配置

## 📝 完整配置示例

### .env.local 完整示例

```env
# ============================================
# 开发环境配置（本地 PostgreSQL）
# ============================================

# 环境标识
NODE_ENV=development

# 本地 PostgreSQL 连接信息
# 请替换为你的实际连接信息
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your-actual-password
DB_NAME=max_tool
```

**注意：**
- `.env.local` 文件不会被提交到 Git（已在 `.gitignore` 中）
- 不要将 `.env.local` 文件提交到代码仓库
- 密码等敏感信息要保密

## 💡 提示

### 如果暂时没有数据库

**可以跳过数据库配置，先开发前端功能：**

1. 不创建 `.env.local` 文件
2. 或创建 `.env.local` 但不填写数据库信息
3. 工具功能可以正常使用，只是使用统计不会保存到数据库

**后续添加数据库：**
- 按照本指南配置数据库
- 添加 `.env.local` 文件
- 重启开发服务器
