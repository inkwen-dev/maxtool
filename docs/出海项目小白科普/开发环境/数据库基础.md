# 数据库基础

## 什么是数据库？

数据库是**存储数据的系统**，类似 Excel 表格，但更强大。

**常见类型：**
- **关系型数据库**：PostgreSQL（表格结构）
- **NoSQL 数据库**：MongoDB（文档结构）

## 基础 SQL

### 1. 创建表

```sql
CREATE TABLE usage_stats (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_name VARCHAR(100) NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
)
```

### 2. 插入数据

```sql
INSERT INTO usage_stats (tool_name) 
VALUES ('draw-lots')
```

### 3. 查询数据

```sql
-- 查询所有
SELECT * FROM usage_stats

-- 条件查询
SELECT * FROM usage_stats 
WHERE tool_name = 'draw-lots'

-- 统计
SELECT tool_name, COUNT(*) as count 
FROM usage_stats 
GROUP BY tool_name
```

## 数据库连接方式

项目支持两种 PostgreSQL 连接方式：

**1. 本地 PostgreSQL 连接**
- 开发环境使用
- 通过 `DB_HOST`, `DB_USER`, `DB_PASSWORD`, `DB_NAME` 连接

**2. Supabase 客户端连接**
- 生产环境使用
- 通过 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY` 连接

**代码自动检测：**
- 如果提供了 Supabase 配置，优先使用 Supabase
- 如果提供了本地 PostgreSQL 配置，使用直接连接
- 代码统一，无需修改业务逻辑
