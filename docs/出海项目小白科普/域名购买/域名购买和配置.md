# 域名购买和配置

## 什么是域名？

域名是网站的**地址**，如 `google.com`、`github.com`。

**组成：**
- **主域名**：`example`（你选择的部分）
- **顶级域名**：`.com`、`.org`、`.net` 等

## 域名选择建议

### 1. 选择原则

- **简短易记**：`freetools.com` ✅
- **相关性强**：与网站内容相关
- **避免数字和连字符**：`free-tools-123.com` ❌

### 2. 顶级域名选择

- **.com**：最常用，最可信（推荐）
- **.cc**：便宜，适合初创
- **.info**：信息类网站
- **.org**：非营利组织

## 配置 DNS

### 1. 获取 Vercel DNS 信息

部署到 Vercel 后：
1. 进入项目 Settings → Domains
2. 添加你的域名
3. Vercel 会显示 DNS 配置

**通常有两种方式：**

**方式 1：CNAME（推荐）**
```
Type: CNAME
Name: @
Value: cname.vercel-dns.com
```

**方式 2：A 记录**
```
Type: A
Name: @
Value: 76.76.21.21
```

### 2. 在域名服务商配置

#### Cloudflare

1. 登录 Cloudflare Dashboard
2. 选择你的域名
3. 进入 "DNS" → "Records"
4. 添加记录：
   - **Type**: CNAME
   - **Name**: @
   - **Target**: `cname.vercel-dns.com`
   - **Proxy**: Off（关闭代理，否则可能有问题）

#### Namecheap

1. 登录 Namecheap
2. 进入 "Domain List" → 选择域名 → "Manage"
3. 进入 "Advanced DNS"
4. 添加 CNAME 记录

## 等待生效

### DNS 传播时间

- **通常**：1-24 小时
- **最快**：几分钟
- **最慢**：48 小时

### 检查是否生效

```bash
# 使用命令行检查
nslookup your-domain.com

# 或使用在线工具
# https://www.whatsmydns.net
```

## HTTPS 证书

### 自动配置

Vercel 会**自动配置 HTTPS**：
- 使用 Let's Encrypt 免费证书
- 自动续期
- 无需手动配置

**等待时间：** DNS 生效后，Vercel 自动申请证书（几分钟到几小时）

## 子域名

### 添加子域名

如果需要 `www.freetools.com`：

1. 在 Vercel 添加 `www.freetools.com`
2. 在 DNS 添加：
   ```
   Type: CNAME
   Name: www
   Value: cname.vercel-dns.com
   ```

### 重定向

Vercel 可以自动重定向：
- `freetools.com` → `www.freetools.com`
- 或 `www.freetools.com` → `freetools.com`

## 域名隐私保护

### 什么是 WHOIS 隐私？

隐藏你的个人信息（姓名、邮箱、电话）在 WHOIS 数据库中。

### 启用方式

**Cloudflare：** 免费自动启用

## 常见问题

### Q: 域名可以转移吗？

A: 可以，但需要等待 60 天（ICANN 规定）

### Q: 如何续费？

A: 域名服务商会提前通知，在到期前续费即可

### Q: 域名过期会怎样？

A: 
- 过期后进入赎回期（30 天）
- 赎回期后可能被他人注册
- 建议设置自动续费
