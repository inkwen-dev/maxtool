# 品牌域名构造指南

## 🎯 构造原则

### 核心要求
- ✅ **独特性**：不能侵犯他人商标（如 Google、Apple 等）
- ✅ **简短易记**：5-10 个字符最佳
- ✅ **朗朗上口**：符合英语发音习惯
- ✅ **品牌感强**：现代、专业、易传播
- ✅ **.com 可用**：优先选择 .com 后缀

### 命名策略
1. **工具词汇组合**：tool + 后缀（io, ly, y, ix）
2. **工具词汇组合**：kit + 后缀（io, ly, y, ix）
3. **工具词汇组合**：app + tool/kit
4. **完全虚构**：类似 canva, figma 的命名风格
5. **动作词 + 工具**：get + tool, use + tool

## 💡 品牌构造方法

### 方法1：工具词 + 后缀

**后缀选择：**
- **io**：现代感强（如 toolio, kitio）
- **ly**：副词感，易记（如 toolly, kitly）
- **y**：形容词感，极简（如 tooly）
- **ix**：科技感（如 toolix, kitix）
- **ux**：用户体验感（如 toolux, kitux）
- **to**：方向感（如 kitto）

**示例：**
- tool + io = toolio
- kit + ly = kitly
- tool + y = tooly

---

### 方法2：工具词组合

**组合方式：**
- app + tool = apptool
- tool + app = toolapp
- app + kit = appkit
- kit + app = kitapp

**示例：**
- apptool.com
- toolapp.com
- appkit.com
- kitapp.com

---

### 方法3：动作词 + 工具词

**动作词选择：**
- get（获取）
- use（使用）
- try（尝试）
- make（制作）
- build（构建）
- create（创建）

**示例：**
- gettool.com
- usetool.com
- trytool.com
- maketool.com

---

### 方法4：完全虚构

**构造方式：**
- tool + 元音（a, e, i, o, u）
- kit + 元音（a, e, i, o, u）
- 工具词 + 简短后缀

**示例：**
- toola.com
- toolo.com
- kitta.com
- kitto.com

## 🚫 避免的命名

### 不能使用的命名

❌ **侵犯商标：**
- googletool.com（Google 是注册商标）
- appletool.com（Apple 是注册商标）
- microsofttool.com（Microsoft 是注册商标）
- amazontool.com（Amazon 是注册商标）

❌ **容易混淆：**
- 与知名品牌过于相似
- 可能被误认为其他品牌

❌ **难以记忆：**
- 过长（>12字符）
- 难以拼写
- 发音困难

## 🔍 域名检查步骤

### 1. 检查可用性
- 使用 Namecheap、GoDaddy 等注册商搜索
- 检查 .com 是否可用

### 2. 检查商标
- 使用 USPTO（美国专利商标局）搜索
- 使用 EUIPO（欧盟知识产权局）搜索
- 确保不侵犯他人商标

### 3. 检查历史
- 使用 archive.org 查看域名历史
- 检查是否有 SEO 惩罚
- 检查是否有不良记录

### 4. 检查社交媒体
- 检查 Twitter、Instagram 等社交媒体账号是否可用
- 确保品牌一致性
