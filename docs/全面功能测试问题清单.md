### 问题2：DrawLots - setInterval 内存泄漏风险 ⚠️

**文件：** `components/tools/DrawLots.tsx`  
**行号：** 40-53  
**严重程度：** 高  
**问题描述：**
```typescript
const interval = setInterval(() => {
  // ...
  if (count >= 10) {
    clearInterval(interval)
    // ...
  }
}, 100)
```
**问题：** 如果组件在 `setInterval` 执行期间卸载，或者用户快速点击按钮，可能导致多个 interval 同时运行，造成内存泄漏。

**修复建议：**
1. 使用 `useRef` 存储 interval ID
2. 在 `useEffect` cleanup 中清理 interval
3. 在开始新的 interval 前清理旧的 interval

### 问题6：WordCounter - 使用统计时机错误 ⚠️

**文件：** `components/tools/WordCounter.tsx`  
**行号：** 66  
**严重程度：** 高  
**问题描述：**
```typescript
useEffect(() => {
  // ...
  trackUsage('word-counter')  // ❌ 错误：在 useEffect 中调用
}, [text])
```
**问题：** 每次文本变化都会调用 `trackUsage`，导致统计数据不准确。应该在用户实际使用工具时调用（如首次输入文本时）。

**修复建议：**
```typescript
const [hasTracked, setHasTracked] = useState(false)

useEffect(() => {
  if (text && !hasTracked) {
    trackUsage('word-counter')
    setHasTracked(true)
  }
  // ... 其他逻辑
}, [text, hasTracked])
```
