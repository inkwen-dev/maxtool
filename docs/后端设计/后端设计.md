## API设计

### 1. 使用统计API

**接口：** `POST /api/track-usage`

**功能：** 记录工具使用情况

**请求：**
```typescript
{
  tool: string  // 工具名称，如 'draw-lots', 'random-number'
}
```

**响应：**
```typescript
{
  success: boolean
}
```

**实现：**

```typescript
// app/api/track-usage/route.ts
import { createClient } from '@supabase/supabase-js'
import { NextResponse } from 'next/server'

// 初始化Supabase客户端
const supabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!
)

export async function POST(request: Request) {
  try {
    // 解析请求体
    const { tool } = await request.json()
    
    // 验证工具名称
    if (!tool || typeof tool !== 'string') {
      return NextResponse.json(
        { success: false, error: 'Invalid tool name' },
        { status: 400 }
      )
    }
    
    // 插入使用记录
    const { error } = await supabase
      .from('usage_stats')
      .insert({ tool_name: tool })
    
    if (error) {
      console.error('Database error:', error)
      return NextResponse.json(
        { success: false, error: 'Database error' },
        { status: 500 }
      )
    }
    
    return NextResponse.json({ success: true })
  } catch (error) {
    console.error('API error:', error)
    return NextResponse.json(
      { success: false, error: 'Internal server error' },
      { status: 500 }
    )
  }
}
```

**错误处理：**
- 400：请求参数错误
- 500：服务器错误

## 错误处理

### 统一错误响应

export const successResponse = (data?: any) => {
  return NextResponse.json({ success: true, ...data })
}

  return NextResponse.json(
    { success: false, error: message },

## 性能优化

### 异步处理

```typescript
// 统计API不阻塞，异步处理
export async function POST(request: Request) {
  // 快速返回响应
  const response = NextResponse.json({ success: true })
  
  // 异步插入数据（不等待）
  request.json().then(({ tool }) => {
    supabase.from('usage_stats').insert({ tool_name: tool })
  }).catch(console.error)
  
  return response
}
```

**注意**：第1期使用同步方式即可，简单可靠。
