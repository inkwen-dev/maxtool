# 搜索功能设计

## 一、搜索内容分析

### 1.1 搜索什么？

**工具信息：**
- 工具名称（如：Draw Lots）
- 工具描述（如：Randomly select from a list）
- 工具分类（如：Random Tools）
- 工具标签（如：抽奖、随机）

**这些信息的特点：**
- ✅ 数量少（20个工具）
- ✅ 变化少（工具列表相对固定）
- ✅ 不需要实时更新
- ✅ 可以前端存储

---

## 二、实现方案对比

### 2.1 方案1：前端搜索（推荐第1期）

**实现方式：**
- 工具列表存储在客户端（JavaScript对象）
- 用户输入时，前端实时搜索
- 不需要后端，不需要数据库

**优点：**
- ✅ 速度快（本地搜索）
- ✅ 不需要后端API
- ✅ 不需要数据库
- ✅ 实现简单
- ✅ 免费（无服务器成本）

**缺点：**
- ⚠️ 工具列表需要包含在页面中
- ⚠️ 如果工具很多（100+），可能影响性能

**适用场景：**
- ✅ 工具数量少（< 50个）
- ✅ 工具列表相对固定
- ✅ 第1期MVP

---

### 2.2 方案2：后端搜索（未来扩展）

**实现方式：**
- 工具信息存储在数据库
- 用户输入时，调用后端API搜索
- 返回搜索结果

**优点：**
- ✅ 可以搜索更多信息（使用统计、标签等）
- ✅ 可以支持复杂搜索（模糊匹配、排序等）
- ✅ 工具列表可以动态更新

**缺点：**
- ⚠️ 需要后端API
- ⚠️ 需要数据库
- ⚠️ 响应速度可能较慢
- ⚠️ 增加服务器成本

**适用场景：**
- ✅ 工具数量多（100+）
- ✅ 需要搜索使用统计
- ✅ 需要复杂搜索功能

### 6.2 搜索函数

```typescript
// lib/search.ts
import { tools, Tool } from './tools-data'

export function searchTools(query: string): Tool[] {
  if (!query.trim()) {
    return []
  }

  const lowerQuery = query.toLowerCase().trim()
  
  return tools.filter(tool => {
    // 搜索名称
    if (tool.name.toLowerCase().includes(lowerQuery)) {
      return true
    }
    
    // 搜索描述
    if (tool.description.toLowerCase().includes(lowerQuery)) {
      return true
    }
    
    // 搜索分类
    if (tool.category.toLowerCase().includes(lowerQuery)) {
      return true
    }
    
    // 搜索标签
    if (tool.tags.some(tag => tag.includes(lowerQuery))) {
      return true
    }
    
    return false
  })
}

// 高级搜索（可选）
export function advancedSearch(query: string, options?: {
  category?: string
  sortBy?: 'name' | 'popularity'
}): Tool[] {
  let results = searchTools(query)
  
  // 按分类筛选
  if (options?.category) {
    results = results.filter(tool => tool.category === options.category)
  }
  
  // 排序
  if (options?.sortBy === 'name') {
    results.sort((a, b) => a.name.localeCompare(b.name))
  }
  
  return results
}
```

### 6.3 搜索组件

```typescript
// components/SearchBox.tsx
'use client'

import { useState, useEffect, useRef } from 'react'
import { searchTools, Tool } from '@/lib/search'
import { useDebounce } from '@/hooks/useDebounce'

export default function SearchBox() {
  const [query, setQuery] = useState('')
  const [results, setResults] = useState<Tool[]>([])
  const [isOpen, setIsOpen] = useState(false)
  const searchRef = useRef<HTMLDivElement>(null)
  
  const debouncedQuery = useDebounce(query, 300)

  useEffect(() => {
    if (debouncedQuery.trim()) {
      const searchResults = searchTools(debouncedQuery)
      setResults(searchResults)
      setIsOpen(true)
    } else {
      setResults([])
      setIsOpen(false)
    }
  }, [debouncedQuery])

  // 点击外部关闭
  useEffect(() => {
    function handleClickOutside(event: MouseEvent) {
      if (searchRef.current && !searchRef.current.contains(event.target as Node)) {
        setIsOpen(false)
      }
    }

    document.addEventListener('mousedown', handleClickOutside)
    return () => document.removeEventListener('mousedown', handleClickOutside)
  }, [])

  return (
    <div ref={searchRef} className="relative">
      <input
        type="text"
        value={query}
        onChange={(e) => setQuery(e.target.value)}
        onFocus={() => query && setIsOpen(true)}
        placeholder="Search tools..."
        className="w-full px-4 py-2 border border-gray-300 rounded-lg focus:outline-none focus:ring-2 focus:ring-blue-500"
      />
      
      {isOpen && results.length > 0 && (
        <div className="absolute top-full mt-2 w-full bg-white border border-gray-200 rounded-lg shadow-lg z-50 max-h-96 overflow-y-auto">
          {results.map(tool => (
            <a
              key={tool.id}
              href={tool.path}
              className="block p-4 hover:bg-gray-50 border-b border-gray-100 last:border-b-0"
              onClick={() => setIsOpen(false)}
            >
              <div className="flex items-center gap-3">
                <span className="text-2xl">{tool.icon}</span>
                <div className="flex-1">
                  <div className="font-semibold text-gray-900">{tool.name}</div>
                  <div className="text-sm text-gray-600">{tool.description}</div>
                  <div className="text-xs text-gray-500 mt-1">{tool.category}</div>
                </div>
              </div>
            </a>
          ))}
        </div>
      )}
      
      {isOpen && query && results.length === 0 && (
        <div className="absolute top-full mt-2 w-full bg-white border border-gray-200 rounded-lg shadow-lg z-50 p-4 text-center text-gray-500">
          No tools found
        </div>
      )}
    </div>
  )
}
```

### 6.4 防抖Hook

```typescript
// hooks/useDebounce.ts
import { useState, useEffect } from 'react'

export function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value)

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value)
    }, delay)

    return () => {
      clearTimeout(handler)
    }
  }, [value, delay])

  return debouncedValue
}
```
