## 🔄 重构内容

### 1. CountdownTimer

**重构前：**
- 手动管理 `useState` 和 `useEffect` 实现倒计时逻辑
- 手动管理 `intervalRef` 和清理逻辑
- 约 70 行计时器相关代码

**重构后：**
- 使用 `useTimer` hook，配置 `type: 'countdown'`
- 使用 `onFinish` 回调处理完成状态
- 使用 `setTime` 动态设置初始时间
- 代码减少约 40 行，逻辑更清晰

**关键改进：**
- ✅ 移除了手动的 `intervalRef` 管理
- ✅ 移除了手动的 `useEffect` 计时逻辑
- ✅ 使用 `onFinish` 回调统一处理完成状态
- ✅ 保持了所有原有功能（开始、暂停、恢复、重置）

## 🔍 技术细节

### useTimer Hook 配置

**CountdownTimer:**
```typescript
useTimer({
  type: 'countdown',
  initialTime: 0,
  interval: 1000,
  onFinish: () => setIsFinished(true),
})
```

**Stopwatch:**
```typescript
useTimer({
  type: 'stopwatch',
  initialTime: 0,
  interval: 10, // 10ms for milliseconds display
})
```

**PomodoroTimer:**
```typescript
useTimer({
  type: 'countdown',
  initialTime: WORK_TIME,
  interval: 1000,
  onFinish: () => {
    // Switch between work/break time
    if (isBreak) {
      setIsBreak(false)
      setTime(WORK_TIME)
      setSessions(prev => prev + 1)
    } else {
      setIsBreak(true)
      setTime(BREAK_TIME)
    }
  },
})
```
