# Dark 模式颜色 UX 评估报告

## 🔍 当前颜色分析

### 当前 Dark 模式 Accent 颜色
- **当前值：** `#2563eb` (blue-600) = `rgb(37, 99, 235)`
- **背景色：** `#0f172a` (slate-900) = `rgb(15, 23, 42)`
- **对比度：** 约 4.5:1（WCAG AA 标准要求 4.5:1）

### 问题分析
1. **视觉舒适度：** ⚠️ blue-600 在深色背景上仍然较亮，可能造成视觉疲劳
2. **品牌识别：** ✅ 保持蓝色品牌色
3. **对比度：** ✅ 符合 WCAG AA 标准

## 🎨 Dark 模式最佳实践

### 主流设计系统的做法

| 设计系统 | Dark 模式主色 | 背景色 | 对比度策略 |
|---------|-------------|--------|-----------|
| **GitHub** | blue-600 | 深灰 | 中等对比度 |
| **Vercel** | blue-500 | 深灰 | 较高对比度 |
| **Linear** | blue-700 | 深灰 | 较低对比度（更柔和）|
| **Notion** | blue-600 | 深灰 | 中等对比度 |

### 推荐方案

**方案 A：使用 blue-700（推荐）**
- `--color-accent: #1d4ed8` (blue-700)
- 更柔和，减少视觉疲劳
- 仍保持足够的对比度（约 4.2:1）

**方案 B：使用 blue-800**
- `--color-accent: #1e40af` (blue-800)
- 非常柔和，但对比度可能略低（约 3.8:1）

**方案 C：使用 slate-blue 混合色**
- 使用更接近背景的蓝灰色
- 保持品牌识别度的同时更柔和

## 💡 推荐调整

### 推荐：使用 blue-700

**理由：**
1. ✅ 更符合 dark 模式的视觉舒适度要求
2. ✅ 保持足够的对比度（WCAG AA）
3. ✅ 保持蓝色品牌识别度
4. ✅ 与主流设计系统（如 Linear）一致

**颜色值：**
```css
.dark {
  --color-accent: #1d4ed8;        /* blue-700 - 更柔和 */
  --color-accent-hover: #1e40af;  /* blue-800 - hover 更暗 */
  --color-accent-light: #2563eb;   /* blue-600 - 用于浅色强调 */
}
```
