# 字数统计工具技术设计文档

## 一、概述

本文档详细描述MaxTool 0.2版本中字数统计工具（Word Counter）的技术设计，包括功能设计、技术实现、组件结构和代码复用等方面。设计严格遵循项目规范，注重代码复用、组件化和性能优化。

## 二、功能设计

### 1. 核心功能

#### 文本统计
- 支持统计字符数（含空格和不含空格）
- 支持统计单词数
- 支持统计句子数
- 支持统计段落数
- 支持统计行数
- 支持统计阅读时间（基于平均阅读速度）
- 支持统计打字时间（基于平均打字速度）

#### 文本分析
- 支持显示词频统计
- 支持显示字符频率统计
- 支持显示最长单词
- 支持显示最短单词

#### 辅助功能
- 支持复制统计结果
- 支持清空输入
- 支持文本导入

### 2. 用户界面

#### 文本输入区域
- 多行文本输入框：用于输入要统计的文本
- 字符实时统计：显示当前输入的字符数
- 清空按钮：快速清空输入内容

#### 统计结果区域
- 统计卡片：显示各项统计结果（字符数、单词数、句子数等）
- 详细统计：显示更详细的统计信息
- 图表展示：使用图表可视化统计结果（可选）

#### 词频分析区域
- 词频列表：显示出现频率最高的词语
- 字符频率：显示字符出现频率

#### 功能按钮
- 复制按钮：复制统计结果
- 清空按钮：清空输入内容
- 导入按钮：导入文本文件

#### 使用说明
- 提供简洁的使用步骤说明

## 三、技术设计

### 1. 技术选型

#### 核心库
- 原生JavaScript：用于文本统计的核心逻辑

#### 浏览器API
- Input API：用于处理文本输入
- Clipboard API：用于复制统计结果
- File API：用于文本文件导入

### 2. 组件结构

#### 主组件

##### WordCounter
- **位置**：`components/tools/WordCounter.tsx`
- **功能**：字数统计工具的主组件
- **结构**：
  ```tsx
  'use client'

  import { useState, useEffect, useMemo } from 'react'
  import Button from '@/components/ui/Button'
  import Textarea from '@/components/ui/Textarea'
  import Card from '@/components/ui/Card'
  import { trackUsage } from '@/lib/tracking'
  import UsageInstructions from '@/components/shared/UsageInstructions'
  import { copyToClipboard } from '@/lib/clipboard-utils'
  import { countText, analyzeText } from '@/lib/text-analysis-service'

  export default function WordCounter() {
    // State declarations
    const [text, setText] = useState('')
    const [hasTracked, setHasTracked] = useState(false)

    // Calculate text statistics
    const statistics = useMemo(() => {
      return countText(text)
    }, [text])

    // Analyze text (word frequency, etc.)
    const analysis = useMemo(() => {
      return analyzeText(text)
    }, [text])

    // Track usage when text is entered
    useEffect(() => {
      if (text && !hasTracked) {
        trackUsage('word-counter')
        setHasTracked(true)
      }
    }, [text, hasTracked])

    // Event handlers
    const handleTextChange = (e: React.ChangeEvent<HTMLTextAreaElement>) => {
      setText(e.target.value)
    }

    const handleCopy = () => {
      const resultText = `
字符数（含空格）: ${statistics.charactersWithSpaces}
字符数（不含空格）: ${statistics.charactersWithoutSpaces}
单词数: ${statistics.words}
句子数: ${statistics.sentences}
段落数: ${statistics.paragraphs}
行数: ${statistics.lines}
阅读时间: ${statistics.readingTime} 分钟
打字时间: ${statistics.typingTime} 分钟
      `.trim()
      copyToClipboard(resultText)
    }

    const handleClear = () => {
      setText('')
    }

    const handleImport = (e: React.ChangeEvent<HTMLInputElement>) => {
      const file = e.target.files?.[0]
      if (file) {
        const reader = new FileReader()
        reader.onload = (event) => {
          const content = event.target?.result as string
          setText(content)
        }
        reader.readAsText(file)
      }
      // Clear the input to allow importing the same file again
      e.target.value = ''
    }

    // Render
    return (
      <div className="space-y-6">
        {/* Text Input Section */}
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">文本输入</h2>
          <div className="relative">
            <Textarea
              value={text}
              onChange={handleTextChange}
              placeholder="请输入要统计的文本..."
              className="w-full h-64"
            />
            <div className="absolute bottom-2 right-2 text-sm text-gray-500">
              {statistics.charactersWithSpaces} 字符（含空格）
            </div>
          </div>
          <div className="flex gap-4">
            <Button onClick={handleClear} variant="outline" size="sm">
              清空
            </Button>
            <label className="inline-flex items-center justify-center px-4 py-2 text-sm font-medium text-gray-700 bg-white border border-gray-300 rounded-md shadow-sm hover:bg-gray-50 focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-blue-500 cursor-pointer">
              导入文件
              <input
                type="file"
                accept=".txt,.md,.docx"
                onChange={handleImport}
                className="hidden"
              />
            </label>
          </div>
        </div>

        {/* Statistics Section */}
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">统计结果</h2>
          
          <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4">
            <Card className="p-4">
              <div className="text-sm text-gray-500">字符数（含空格）</div>
              <div className="text-3xl font-bold">{statistics.charactersWithSpaces}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">字符数（不含空格）</div>
              <div className="text-3xl font-bold">{statistics.charactersWithoutSpaces}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">单词数</div>
              <div className="text-3xl font-bold">{statistics.words}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">句子数</div>
              <div className="text-3xl font-bold">{statistics.sentences}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">段落数</div>
              <div className="text-3xl font-bold">{statistics.paragraphs}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">行数</div>
              <div className="text-3xl font-bold">{statistics.lines}</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">阅读时间</div>
              <div className="text-3xl font-bold">{statistics.readingTime} 分钟</div>
            </Card>
            
            <Card className="p-4">
              <div className="text-sm text-gray-500">打字时间</div>
              <div className="text-3xl font-bold">{statistics.typingTime} 分钟</div>
            </Card>
          </div>
        </div>

        {/* Text Analysis Section */}
        {text && (
          <div className="space-y-4">
            <h2 className="text-xl font-semibold">文本分析</h2>
            
            <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
              {/* Word Frequency */}
              <div className="space-y-2">
                <h3 className="text-lg font-medium">词频统计</h3>
                <div className="p-4 bg-gray-100 rounded-lg max-h-60 overflow-y-auto">
                  {analysis.wordFrequency.length > 0 ? (
                    <ul className="space-y-1">
                      {analysis.wordFrequency.slice(0, 10).map((item, index) => (
                        <li key={index} className="flex justify-between">
                          <span>{item.word}</span>
                          <span className="font-semibold">{item.count}</span>
                        </li>
                      ))}
                    </ul>
                  ) : (
                    <p className="text-gray-500">无数据</p>
                  )}
                </div>
              </div>
              
              {/* Character Frequency */}
              <div className="space-y-2">
                <h3 className="text-lg font-medium">字符频率</h3>
                <div className="p-4 bg-gray-100 rounded-lg max-h-60 overflow-y-auto">
                  {analysis.characterFrequency.length > 0 ? (
                    <ul className="space-y-1">
                      {analysis.characterFrequency.slice(0, 10).map((item, index) => (
                        <li key={index} className="flex justify-between">
                          <span>{item.character || '空格'}</span>
                          <span className="font-semibold">{item.count}</span>
                        </li>
                      ))}
                    </ul>
                  ) : (
                    <p className="text-gray-500">无数据</p>
                  )}
                </div>
              </div>
            </div>
            
            {/* Additional Analysis */}
            <div className="grid grid-cols-1 md:grid-cols-3 gap-4">
              <Card className="p-4">
                <div className="text-sm text-gray-500">最长单词</div>
                <div className="text-xl font-bold">{analysis.longestWord || '无'}</div>
              </Card>
              
              <Card className="p-4">
                <div className="text-sm text-gray-500">最短单词</div>
                <div className="text-xl font-bold">{analysis.shortestWord || '无'}</div>
              </Card>
              
              <Card className="p-4">
                <div className="text-sm text-gray-500">平均单词长度</div>
                <div className="text-xl font-bold">{analysis.averageWordLength.toFixed(2)} 字符</div>
              </Card>
            </div>
          </div>
        )}

        {/* Action Buttons */}
        {text && (
          <div className="flex gap-4">
            <Button onClick={handleCopy} variant="primary" size="lg">
              复制统计结果
            </Button>
          </div>
        )}

        {/* Usage Instructions */}
        <UsageInstructions
          steps={[
            '在文本输入框中输入要统计的文本，或点击"导入文件"按钮导入文本文件',
            '系统会实时统计文本的各项指标',
            '查看统计结果区域的各项统计数据',
            '在文本分析区域查看词频和字符频率统计',
            '点击"复制统计结果"按钮复制所有统计数据',
            '点击"清空"按钮清空输入内容'
          ]}
        />
      </div>
    )
  }
  ```

### 4. 工具函数设计

#### TextAnalysisService

- **位置**：`lib/text-analysis-service.ts`
- **功能**：封装文本分析的核心逻辑
- **API**：
  ```typescript
  /**
   * 文本统计结果接口
   */
  export interface TextStatistics {
    charactersWithSpaces: number;
    charactersWithoutSpaces: number;
    words: number;
    sentences: number;
    paragraphs: number;
    lines: number;
    readingTime: number;
    typingTime: number;
  }

  /**
   * 文本分析结果接口
   */
  export interface TextAnalysis {
    wordFrequency: Array<{ word: string; count: number }>;
    characterFrequency: Array<{ character: string; count: number }>;
    longestWord: string;
    shortestWord: string;
    averageWordLength: number;
  }

  /**
   * 统计文本的各项指标
   * @param text - 要统计的文本
   * @returns 统计结果
   */
  export function countText(text: string): TextStatistics;

  /**
   * 分析文本内容
   * @param text - 要分析的文本
   * @returns 分析结果
   */
  export function analyzeText(text: string): TextAnalysis;

  /**
   * 计算阅读时间
   * @param wordCount - 单词数
   * @param wordsPerMinute - 每分钟阅读单词数（默认200）
   * @returns 阅读时间（分钟）
   */
  export function calculateReadingTime(wordCount: number, wordsPerMinute: number = 200): number;

  /**
   * 计算打字时间
   * @param characterCount - 字符数
   * @param charactersPerMinute - 每分钟打字数（默认40）
   * @returns 打字时间（分钟）
   */
  export function calculateTypingTime(characterCount: number, charactersPerMinute: number = 40): number;
  ```
