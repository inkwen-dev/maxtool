# 随机密码生成器技术设计文档

## 1. 概述

随机密码生成器是一款帮助用户生成高强度随机密码的在线工具。用户可以自定义密码长度、包含字符类型（大写字母、小写字母、数字、特殊字符等），生成安全可靠的密码。

## 2. 功能设计

### 2.1 核心功能
- 自定义密码长度（4-128位）
- 可选择包含的字符类型：
  - 大写字母（A-Z）
  - 小写字母（a-z）
  - 数字（0-9）
  - 特殊字符（!@#$%^&*等）
- 排除相似字符（如0和O，1和l等）
- 排除自定义字符
- 生成多个密码（最多10个）
- 密码强度显示
- 实时预览
- 复制功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `PasswordGeneratorTool`: 主组件，包含所有功能
  - `PasswordSettings`: 密码设置组件（长度、字符类型等）

  - `PasswordStrength`: 密码强度显示组件
  - `ActionButtons`: 操作按钮（生成、复制、重置）

### 3.2 核心实现逻辑
```javascript
// 生成随机密码
const generatePassword = (settings) => {
  const { 
    length = 12, 
    includeUppercase = true, 
    includeLowercase = true, 
    includeNumbers = true, 
    includeSymbols = true, 
    excludeSimilar = false, 
    excludeChars = '' 
  } = settings

  // 字符集定义
  const uppercaseChars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZ'
  const lowercaseChars = 'abcdefghijklmnopqrstuvwxyz'
  const numberChars = '0123456789'
  const symbolChars = '!@#$%^&*()_+-=[]{}|;:,.<>?'
  const similarChars = '0O1lI'

  // 构建字符集
  let charset = ''
  if (includeUppercase) charset += uppercaseChars
  if (includeLowercase) charset += lowercaseChars
  if (includeNumbers) charset += numberChars
  if (includeSymbols) charset += symbolChars

  // 排除相似字符
  if (excludeSimilar) {
    charset = charset.split('').filter(char => !similarChars.includes(char)).join('')
  }

  // 排除自定义字符
  if (excludeChars) {
    charset = charset.split('').filter(char => !excludeChars.includes(char)).join('')
  }

  // 检查字符集是否为空
  if (!charset) {
    throw new Error('No characters available for password generation')
  }

  // 生成密码
  let password = ''
  for (let i = 0; i < length; i++) {
    const randomIndex = Math.floor(Math.random() * charset.length)
    password += charset[randomIndex]
  }

  return password
}

// 生成多个密码
const generateMultiplePasswords = (settings, count = 1) => {
  const passwords = []
  for (let i = 0; i < count; i++) {
    passwords.push(generatePassword(settings))
  }
  return passwords
}

// 计算密码强度
const calculatePasswordStrength = (password) => {
  const length = password.length
  let strength = 0

  // 长度检查
  if (length >= 12) strength += 25
  else if (length >= 8) strength += 15
  else strength += 5

  // 字符类型检查
  if (/[a-z]/.test(password)) strength += 15
  if (/[A-Z]/.test(password)) strength += 15
  if (/[0-9]/.test(password)) strength += 15
  if (/[^a-zA-Z0-9]/.test(password)) strength += 15

  // 复杂度检查
  if (/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&])[A-Za-z\d@$!%*?&]/.test(password)) {
    strength += 10
  }

  return Math.min(strength, 100)
}

// 获取密码强度等级
const getPasswordStrengthLevel = (strength) => {
  if (strength < 30) return 'weak'
  if (strength < 60) return 'medium'
  if (strength < 80) return 'strong'
  return 'very_strong'
}
```

```typescript
interface PasswordSettings {
  length: number
  includeUppercase: boolean
  includeLowercase: boolean
  includeNumbers: boolean
  includeSymbols: boolean
  excludeSimilar: boolean
  excludeChars: string
  count: number
}

interface PasswordStrengthResult {
  strength: number
  level: 'weak' | 'medium' | 'strong' | 'very_strong'
}

interface PasswordGeneratorState {
  passwords: string[]
  settings: PasswordSettings
  isGenerating: boolean
  strengthResults: PasswordStrengthResult[]
}
```
