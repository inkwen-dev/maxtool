# 日期时间计算器技术设计文档

## 一、概述

本文档详细描述MaxTool 0.2版本中日期时间计算器（DateTime Calculator）工具的技术设计，包括功能设计、技术实现、组件结构和代码复用等方面。设计严格遵循项目规范，注重代码复用、组件化和性能优化。

## 二、功能设计

### 1. 核心功能

#### 日期时间计算
- 支持日期时间的加减运算
- 支持添加/减去年、月、日、小时、分钟、秒
- 支持两个日期时间之间的差值计算
- 支持工作日计算（排除周末）

#### 时间单位转换
- 支持将毫秒转换为天、小时、分钟、秒
- 支持将天、小时、分钟、秒转换为毫秒

#### 辅助功能
- 支持复制计算结果
- 支持重置计算器

### 2. 用户界面

#### 计算模式选择
- 单选按钮组：选择计算模式（日期加减、日期差值、工作日计算、时间单位转换）

#### 日期时间输入
- 日期选择器：用于选择起始日期
- 时间选择器：用于选择起始时间

#### 计算参数
- 数值输入框：用于输入要加减的数值
- 单位选择器：选择要加减的时间单位

#### 输出区域
- 计算结果显示：显示计算后的日期时间或差值
- 详细结果分析：显示计算的详细过程和结果

#### 功能按钮
- 计算按钮：执行计算操作
- 复制按钮：复制计算结果
- 重置按钮：重置所有输入

#### 使用说明
- 提供简洁的使用步骤说明

## 三、技术设计

### 1. 技术选型

#### 核心库
- 原生JavaScript：用于日期时间的基本计算
- date-fns：用于高级日期时间操作和格式化

#### 浏览器API
- Input API：用于处理数值输入
- Clipboard API：用于复制计算结果
- Date API：用于处理日期时间

### 2. 组件结构

#### 主组件

##### DateTimeCalculator
- **位置**：`components/tools/DateTimeCalculator.tsx`
- **功能**：日期时间计算器工具的主组件
- **结构**：
  ```tsx
  'use client'

  import { useState } from 'react'
  import Button from '@/components/ui/Button'
  import Input from '@/components/ui/Input'
  import Select from '@/components/ui/Select'
  import DatePicker from '@/components/ui/DatePicker'
  import TimePicker from '@/components/ui/TimePicker'
  import { trackUsage } from '@/lib/tracking'
  import UsageInstructions from '@/components/shared/UsageInstructions'
  import { copyToClipboard } from '@/lib/clipboard-utils'
  import { calculateDateTime, convertTimeUnits } from '@/lib/date-time-service'

  // 计算模式类型
  type CalculationMode = 'add-subtract' | 'difference' | 'workday' | 'unit-conversion'

  // 时间单位类型
  type TimeUnit = 'year' | 'month' | 'day' | 'hour' | 'minute' | 'second'

  export default function DateTimeCalculator() {
    // State declarations
    const [mode, setMode] = useState<CalculationMode>('add-subtract')
    const [startDate, setStartDate] = useState(new Date())
    const [endDate, setEndDate] = useState(new Date())
    const [value, setValue] = useState(1)
    const [unit, setUnit] = useState<TimeUnit>('day')
    const [result, setResult] = useState<string>('')
    const [detailedResult, setDetailedResult] = useState<string>('')
    const [hasTracked, setHasTracked] = useState(false)

    // Event handlers
    const handleCalculate = () => {
      try {
        let calculationResult: string
        let calculationDetails: string

        switch (mode) {
          case 'add-subtract':
            const resultDate = calculateDateTime(startDate, value, unit)
            calculationResult = resultDate.toISOString()
            calculationDetails = `计算结果：${resultDate.toLocaleString()}`
            break
          case 'difference':
            const diff = calculateDateTime(startDate, endDate)
            calculationResult = JSON.stringify(diff)
            calculationDetails = `日期差值：${diff.days}天 ${diff.hours}小时 ${diff.minutes}分钟 ${diff.seconds}秒`
            break
          case 'workday':
            const workdayResult = calculateDateTime(startDate, value, unit, true)
            calculationResult = workdayResult.toISOString()
            calculationDetails = `工作日计算结果：${workdayResult.toLocaleString()}`
            break
          case 'unit-conversion':
            const conversionResult = convertTimeUnits(value, unit)
            calculationResult = JSON.stringify(conversionResult)
            calculationDetails = `时间单位转换结果：${conversionResult.milliseconds}毫秒 = ${conversionResult.days}天 ${conversionResult.hours}小时 ${conversionResult.minutes}分钟 ${conversionResult.seconds}秒`
            break
        }

        setResult(calculationResult)
        setDetailedResult(calculationDetails)

        // Track usage
        if (!hasTracked) {
          trackUsage('date-time-calculator')
          setHasTracked(true)
        }
      } catch (error) {
        console.error('Calculation error:', error)
        setResult('计算失败，请检查输入参数')
        setDetailedResult('')
      }
    }

    const handleCopy = () => {
      copyToClipboard(result)
    }

    const handleReset = () => {
      setStartDate(new Date())
      setEndDate(new Date())
      setValue(1)
      setUnit('day')
      setResult('')
      setDetailedResult('')
    }

    // Render
    return (
      <div className="space-y-6">
        {/* Mode Selection */}
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">计算模式</h2>
          <div className="flex flex-wrap gap-4">
            <label className="inline-flex items-center space-x-2">
              <input
                type="radio"
                value="add-subtract"
                checked={mode === 'add-subtract'}
                onChange={(e) => setMode(e.target.value as CalculationMode)}
                className="form-radio"
              />
              <span>日期加减</span>
            </label>
            <label className="inline-flex items-center space-x-2">
              <input
                type="radio"
                value="difference"
                checked={mode === 'difference'}
                onChange={(e) => setMode(e.target.value as CalculationMode)}
                className="form-radio"
              />
              <span>日期差值</span>
            </label>
            <label className="inline-flex items-center space-x-2">
              <input
                type="radio"
                value="workday"
                checked={mode === 'workday'}
                onChange={(e) => setMode(e.target.value as CalculationMode)}
                className="form-radio"
              />
              <span>工作日计算</span>
            </label>
            <label className="inline-flex items-center space-x-2">
              <input
                type="radio"
                value="unit-conversion"
                checked={mode === 'unit-conversion'}
                onChange={(e) => setMode(e.target.value as CalculationMode)}
                className="form-radio"
              />
              <span>时间单位转换</span>
            </label>
          </div>
        </div>

        {/* Input Section */}
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">输入参数</h2>
          
          {mode !== 'unit-conversion' && (
            <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
              <div className="space-y-2">
                <label className="block">起始日期</label>
                <DatePicker
                  value={startDate}
                  onChange={setStartDate}
                  className="w-full"
                />
              </div>
              
              <div className="space-y-2">
                <label className="block">起始时间</label>
                <TimePicker
                  value={startDate}
                  onChange={setStartDate}
                  className="w-full"
                />
              </div>
            </div>
          )}

          {(mode === 'difference') && (
            <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
              <div className="space-y-2">
                <label className="block">结束日期</label>
                <DatePicker
                  value={endDate}
                  onChange={setEndDate}
                  className="w-full"
                />
              </div>
              
              <div className="space-y-2">
                <label className="block">结束时间</label>
                <TimePicker
                  value={endDate}
                  onChange={setEndDate}
                  className="w-full"
                />
              </div>
            </div>
          )}

          {(mode === 'add-subtract' || mode === 'workday' || mode === 'unit-conversion') && (
            <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
              <div className="space-y-2">
                <label className="block">数值</label>
                <Input
                  type="number"
                  value={value}
                  onChange={(e) => setValue(parseFloat(e.target.value))}
                  min="0"
                  step="1"
                  className="w-full"
                />
              </div>
              
              <div className="space-y-2">
                <label className="block">单位</label>
                <Select
                  value={unit}
                  onChange={(e) => setUnit(e.target.value as TimeUnit)}
                  className="w-full"
                >
                  <option value="year">年</option>
                  <option value="month">月</option>
                  <option value="day">日</option>
                  <option value="hour">小时</option>
                  <option value="minute">分钟</option>
                  <option value="second">秒</option>
                </Select>
              </div>
            </div>
          )}
        </div>

        {/* Action Buttons */}
        <div className="flex gap-4">
          <Button onClick={handleCalculate} variant="primary" size="lg">
            计算
          </Button>
          {result && (
            <Button onClick={handleCopy} variant="secondary" size="lg">
              复制结果
            </Button>
          )}
          <Button onClick={handleReset} variant="outline" size="lg">
            重置
          </Button>
        </div>

        {/* Result Section */}
        {result && (
          <div className="space-y-4">
            <h2 className="text-xl font-semibold">计算结果</h2>
            <div className="p-4 bg-gray-100 rounded-lg">
              <pre className="whitespace-pre-wrap">{detailedResult}</pre>
            </div>
          </div>
        )}

        {/* Usage Instructions */}
        <UsageInstructions
          steps={[
            '选择计算模式（日期加减、日期差值、工作日计算或时间单位转换）',
            '根据选择的模式输入相应的日期时间和参数',
            '点击"计算"按钮执行计算',
            '查看计算结果和详细信息',
            '点击"复制结果"按钮复制计算结果'
          ]}
        />
      </div>
    )
  }
  ```

### 4. 工具函数设计

#### DateTimeService

- **位置**：`lib/date-time-service.ts`
- **功能**：封装日期时间计算的核心逻辑
- **API**：
  ```typescript
  /**
   * 日期时间加减计算
   * @param date - 起始日期时间
   * @param value - 要加减的数值
   * @param unit - 时间单位
   * @param workdayOnly - 是否仅计算工作日
   * @returns 计算后的日期时间
   */
  export function calculateDateTime(
    date: Date,
    value: number,
    unit: TimeUnit,
    workdayOnly: boolean = false
  ): Date;

  /**
   * 计算两个日期时间之间的差值
   * @param startDate - 起始日期时间
   * @param endDate - 结束日期时间
   * @returns 差值对象，包含天、小时、分钟、秒
   */
  export function calculateDateDifference(
    startDate: Date,
    endDate: Date
  ): {
    days: number;
    hours: number;
    minutes: number;
    seconds: number;
  };

  /**
   * 时间单位转换
   * @param value - 要转换的数值
   * @param unit - 输入的时间单位
   * @returns 转换结果对象，包含各种时间单位的转换值
   */
  export function convertTimeUnits(
    value: number,
    unit: TimeUnit
  ): {
    milliseconds: number;
    seconds: number;
    minutes: number;
    hours: number;
    days: number;
  };
  ```
