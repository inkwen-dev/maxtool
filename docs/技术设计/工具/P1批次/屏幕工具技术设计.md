# 屏幕工具技术设计文档

## 1. 概述

屏幕工具是一款帮助用户测量和调整屏幕参数的在线工具。用户可以测量屏幕尺寸、颜色、分辨率等参数，以及获取屏幕截图和屏幕录制功能。

## 2. 功能设计

### 2.1 核心功能
- 屏幕尺寸测量（宽度、高度、对角线）
- 屏幕分辨率检测
- 屏幕颜色检测
- 屏幕截图功能
- 屏幕录制功能
- 屏幕像素密度检测
- 屏幕比例计算
- 实时预览
- 复制和下载功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `ScreenTools`: 主组件，包含所有功能
  - `ScreenSize`: 屏幕尺寸测量组件
  - `ScreenResolution`: 屏幕分辨率检测组件
  - `ScreenColor`: 屏幕颜色检测组件
  - `ScreenCapture`: 屏幕截图和录制组件
  - `PixelDensity`: 像素密度检测组件
  - `ScreenRatio`: 屏幕比例计算组件
  - `ActionButtons`: 操作按钮（测量、截图、录制、复制、下载）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 获取屏幕尺寸
const getScreenSize = () => {
  return {
    width: window.screen.width,
    height: window.screen.height,
    availableWidth: window.screen.availWidth,
    availableHeight: window.screen.availHeight,
    colorDepth: window.screen.colorDepth,
    pixelDepth: window.screen.pixelDepth,
    orientation: window.screen.orientation.type
  }
}

// 获取屏幕分辨率
const getScreenResolution = () => {
  return {
    width: window.innerWidth,
    height: window.innerHeight,
    devicePixelRatio: window.devicePixelRatio,
    dpr: window.devicePixelRatio
  }
}

// 获取像素密度
const getPixelDensity = () => {
  const dpr = window.devicePixelRatio
  return {
    dpr,
    ppi: Math.round(dpr * 96), // 96 DPI 是标准屏幕的像素密度
    scale: `${(dpr * 100).toFixed(0)}%`
  }
}

// 计算屏幕比例
const calculateScreenRatio = () => {
  const width = window.screen.width
  const height = window.screen.height
  const gcd = (a, b) => (b === 0 ? a : gcd(b, a % b))
  const commonDivisor = gcd(width, height)
  return `${width / commonDivisor}:${height / commonDivisor}`
}

// 屏幕截图
const captureScreenshot = async () => {
  try {
    // 使用浏览器的屏幕截图API
    const stream = await navigator.mediaDevices.getDisplayMedia({ video: true })
    const video = document.createElement('video')
    video.srcObject = stream
    
    await new Promise((resolve) => {
      video.onloadedmetadata = () => {
        video.play()
        resolve()
      }
    })
    
    const canvas = document.createElement('canvas')
    canvas.width = video.videoWidth
    canvas.height = video.videoHeight
    const ctx = canvas.getContext('2d')
    ctx.drawImage(video, 0, 0)
    
    // 停止流
    stream.getTracks().forEach(track => track.stop())
    
    // 返回Base64编码的图片
    return canvas.toDataURL('image/png')
  } catch (error) {
    throw new Error('Failed to capture screenshot: ' + error.message)
  }
}

// 屏幕录制
const startScreenRecording = async () => {
  try {
    const stream = await navigator.mediaDevices.getDisplayMedia({ video: true, audio: false })
    const mediaRecorder = new MediaRecorder(stream)
    const chunks = []
    
    mediaRecorder.ondataavailable = (e) => {
      if (e.data.size > 0) {
        chunks.push(e.data)
      }
    }
    
    mediaRecorder.onstop = () => {
      const blob = new Blob(chunks, { type: 'video/webm' })
      const url = URL.createObjectURL(blob)
      // 下载录制的视频
      const a = document.createElement('a')
      a.href = url
      a.download = 'screen-recording.webm'
      a.click()
      URL.revokeObjectURL(url)
    }
    
    mediaRecorder.start()
    return { mediaRecorder, stream }
  } catch (error) {
    throw new Error('Failed to start screen recording: ' + error.message)
  }
}
```

## 4. 数据结构

```typescript
interface ScreenSize {
  width: number
  height: number
  availableWidth: number
  availableHeight: number
  colorDepth: number
  pixelDepth: number
  orientation: string
}

interface ScreenResolution {
  width: number
  height: number
  devicePixelRatio: number
  dpr: number
}

interface PixelDensity {
  dpr: number
  ppi: number
  scale: string
}

interface ScreenToolsState {
  screenSize: ScreenSize | null
  screenResolution: ScreenResolution | null
  pixelDensity: PixelDensity | null
  screenRatio: string | null
  screenshotData: string | null
  isRecording: boolean
  mediaRecorder: MediaRecorder | null
  isLoading: boolean
}
```
