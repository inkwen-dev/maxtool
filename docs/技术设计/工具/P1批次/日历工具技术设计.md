# 日历工具技术设计文档

## 1. 概述

日历工具是一款提供日期查看、事件管理和日历视图切换功能的在线工具。用户可以查看月、周、日不同视图的日历，添加和管理个人事件，以及进行日期相关的操作。

## 2. 功能设计

### 2.1 核心功能
- 多视图切换（月视图、周视图、日视图）
- 事件添加和编辑
- 事件提醒功能
- 日期导航（上一月/下一月，上一周/下一周，今天）
- 节日和重要日期标记
- 打印和导出功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和帮助

## 3. 技术设计

### 3.1 组件结构
- `CalendarTool`: 主组件，包含所有功能
  - `CalendarHeader`: 日历头部（标题、导航、视图切换）
  - `MonthView`: 月视图组件
  - `WeekView`: 周视图组件
  - `DayView`: 日视图组件
  - `EventForm`: 事件添加/编辑表单
  - `EventList`: 事件列表组件
  - `HolidayList`: 节日列表组件
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 生成日历数据
const generateCalendarData = (year, month) => {
  const firstDay = new Date(year, month, 1)
  const lastDay = new Date(year, month + 1, 0)
  const startDate = new Date(firstDay)
  startDate.setDate(firstDay.getDate() - firstDay.getDay())
  
  const calendarData = []
  const weeks = []
  
  // 生成6周的日历数据
  for (let week = 0; week < 6; week++) {
    const days = []
    for (let day = 0; day < 7; day++) {
      const date = new Date(startDate)
      date.setDate(startDate.getDate() + (week * 7 + day))
      
      days.push({
        date,
        isCurrentMonth: date.getMonth() === month,
        isToday: date.toDateString() === new Date().toDateString(),
        events: []
      })
    }
    weeks.push(days)
  }
  
  return {
    year,
    month,
    weeks,
    firstDay,
    lastDay
  }
}

// 添加事件
const addEvent = (events, event) => {
  return [...events, {
    id: Date.now().toString(),
    ...event,
    createdAt: new Date(),
    updatedAt: new Date()
  }]
}

// 编辑事件
const editEvent = (events, eventId, updatedEvent) => {
  return events.map(event => 
    event.id === eventId 
      ? { ...event, ...updatedEvent, updatedAt: new Date() }
      : event
  )
}
```

## 4. 数据结构

```typescript
type CalendarView = 'month' | 'week' | 'day'

interface CalendarEvent {
  id: string
  title: string
  description?: string
  startDate: Date
  endDate: Date
  location?: string
  color?: string
  isAllDay: boolean
  reminders?: Date[]
  createdAt: Date
  updatedAt: Date
}

interface CalendarDay {
  date: Date
  isCurrentMonth: boolean
  isToday: boolean
  events: CalendarEvent[]
}

interface CalendarWeek {
  days: CalendarDay[]
}

interface CalendarData {
  year: number
  month: number
  weeks: CalendarWeek[]
  firstDay: Date
  lastDay: Date
}

interface CalendarState {
  currentView: CalendarView
  currentDate: Date
  selectedDate: Date
  events: CalendarEvent[]
  isEventFormOpen: boolean
  editingEvent: CalendarEvent | null
  holidays: Holiday[]
}

interface Holiday {
  date: Date
  name: string
  description?: string
}
```
