# 世界时间工具技术设计文档

## 1. 概述

世界时间工具是一款显示全球主要城市当前时间的在线工具。用户可以查看不同城市的当地时间，比较多个城市的时差，并设置自己关注的城市列表。

## 2. 功能设计

### 2.1 核心功能
- 显示全球主要城市的当前时间
- 支持添加/删除关注的城市
- 支持搜索城市
- 实时时间更新
- 24小时/12小时制切换
- 显示日期信息
- 显示日出日落时间（可选）
- 显示时区信息

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `WorldTimeTool`: 主组件，包含所有功能
  - `CitySearch`: 城市搜索组件
  - `CityList`: 城市列表组件（显示关注的城市）
  - `WorldClock`: 世界时钟组件（显示所有城市的时间）
  - `TimeSettings`: 时间设置组件（24小时/12小时制等）
  - `ActionButtons`: 操作按钮（添加城市、删除城市、重置）
  - `UsageInstructions`: 使用说明组件

```javascript
// 获取城市当前时间
const getCityTime = (cityTimezone) => {
  const now = new Date()
  const formatter = new Intl.DateTimeFormat('en-US', {
    timeZone: cityTimezone,
    hour: '2-digit',
    minute: '2-digit',
    second: '2-digit',
    hour12: false,
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
    weekday: 'long'
  })
  
  const formattedTime = formatter.format(now)
  const [weekday, date, time] = formattedTime.split(', ')
  
  return {
    time,
    date,
    weekday,
    timestamp: now.getTime()
  }
}

// 24小时制转12小时制
const convertTo12HourFormat = (time24) => {
  const [hour, minute, second] = time24.split(':')
  const hourInt = parseInt(hour)
  const period = hourInt >= 12 ? 'PM' : 'AM'
  const hour12 = hourInt % 12 || 12
  return `${hour12}:${minute}:${second} ${period}`
}

// 搜索城市
const searchCities = (cities, query) => {
  if (!query) return []
  const lowercaseQuery = query.toLowerCase()
  return cities.filter(city => 
    city.name.toLowerCase().includes(lowercaseQuery) ||
    city.timezone.toLowerCase().includes(lowercaseQuery)
  )
}
```
