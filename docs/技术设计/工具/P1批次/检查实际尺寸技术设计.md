# 检查实际尺寸技术设计文档

## 1. 概述

检查实际尺寸是一款帮助用户在屏幕上检查物体实际尺寸的在线工具。用户可以上传图片或使用屏幕上的参考物，通过校准后测量物体的实际尺寸。

## 2. 功能设计

### 2.1 核心功能
- 支持上传图片或使用屏幕截图
- 提供参考线和测量工具
- 校准功能（使用已知尺寸的参考物）
- 测量物体的长度、宽度和面积
- 支持公制和英制单位切换
- 实时预览和测量结果显示
- 测量结果复制功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例
- 图片缩放和拖动功能

## 3. 技术设计

### 3.1 组件结构
- `CheckActualSizeTool`: 主组件，包含所有功能
  - `ImageUploader`: 图片上传组件

  - `ImageViewer`: 图片查看器组件（支持缩放和拖动）
  - `CalibrationControls`: 校准控制组件
  - `MeasurementTools`: 测量工具组件（参考线、尺子、矩形测量）

  - `MeasurementDisplay`: 测量结果显示组件
  - `ActionButtons`: 操作按钮（复制结果、校准）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 工具状态管理
const [toolState, setToolState] = useState({
  image: null,
  calibration: 1,
  unit: 'metric', // 默认公制单位
  measurements: [],
  currentTool: 'ruler', // 当前测量工具
  isCalibrating: false
})

// 计算像素到实际尺寸的转换
const pixelsToActualSize = (pixels) => {
  if (toolState.unit === 'metric') {
    // 转换为厘米
    return pixels / (37.795275591 * toolState.calibration)
  } else {
    // 转换为英寸
    return pixels / (96 * toolState.calibration)
  }
}

// 计算实际尺寸到像素的转换
const actualSizeToPixels = (size) => {
  if (toolState.unit === 'metric') {
    // 从厘米转换
    return size * 37.795275591 * toolState.calibration
  } else {
    // 从英寸转换
    return size * 96 * toolState.calibration
  }
}

// 校准功能
const calibrate = (knownSize, measuredPixels) => {
  const newCalibration = measuredPixels / (toolState.unit === 'metric' ? knownSize * 37.795275591 : knownSize * 96)
  setToolState(prev => ({ ...prev, calibration: newCalibration }))
}

// 测量长度
const measureLength = (startX, startY, endX, endY) => {
  const pixels = Math.sqrt(Math.pow(endX - startX, 2) + Math.pow(endY - startY, 2))
  const actualLength = pixelsToActualSize(pixels)
  
  const newMeasurement = {
    id: Date.now(),
    type: 'length',
    start: { x: startX, y: startY },
    end: { x: endX, y: endY },
    length: actualLength,
    unit: toolState.unit
  }
  
  setToolState(prev => ({
    ...prev,
    measurements: [...prev.measurements, newMeasurement]
  }))
  
  return newMeasurement
}

// 测量矩形（面积）
const measureRectangle = (x, y, width, height) => {
  const actualWidth = pixelsToActualSize(width)
  const actualHeight = pixelsToActualSize(height)
  const actualArea = actualWidth * actualHeight
  
  const newMeasurement = {
    id: Date.now(),
    type: 'rectangle',
    x: x,
    y: y,
    width: actualWidth,
    height: actualHeight,
    area: actualArea,
    unit: toolState.unit
  }
  
  setToolState(prev => ({
    ...prev,
    measurements: [...prev.measurements, newMeasurement]
  }))
  
  return newMeasurement
}

// 上传图片
const handleImageUpload = (e) => {
  const file = e.target.files[0]
  if (file) {
    const reader = new FileReader()
    reader.onload = (event) => {
      setToolState(prev => ({
        ...prev,
        image: event.target.result
      }))
    }
    reader.readAsDataURL(file)
  }
}
```

## 4. 数据结构

```typescript
type MeasurementUnit = 'metric' | 'imperial'
type MeasurementType = 'length' | 'rectangle'

interface Point {
  x: number
  y: number
}

interface LengthMeasurement {
  id: number
  type: 'length'
  start: Point
  end: Point
  length: number
  unit: MeasurementUnit
}

interface RectangleMeasurement {
  id: number
  type: 'rectangle'
  x: number
  y: number
  width: number
  height: number
  area: number
  unit: MeasurementUnit
}

type Measurement = LengthMeasurement | RectangleMeasurement

type MeasurementTool = 'ruler' | 'rectangle' | 'reference-line'

interface CheckActualSizeState {
  image: string | null
  calibration: number
  unit: MeasurementUnit
  measurements: Measurement[]
  currentTool: MeasurementTool
  isCalibrating: boolean
  imageScale: number
  imageOffsetX: number
  imageOffsetY: number
}
```
