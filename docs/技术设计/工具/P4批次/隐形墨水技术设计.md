# 隐形墨水技术设计文档

## 1. 概述

隐形墨水是一款帮助用户生成和解码隐形文本的在线工具。用户可以输入普通文本，工具会将其转换为看似空白但实际包含隐藏信息的文本（使用Unicode零宽字符实现），也可以解码包含隐藏信息的文本。

## 2. 功能设计

### 2.1 核心功能
- 将普通文本转换为隐形墨水文本（使用零宽字符）
- 解码隐形墨水文本，还原原始信息
- 实时预览效果
- 复制功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `InvisibleInkTool`: 主组件，包含所有功能
  - `TextInput`: 文本输入组件

  - `TextPreview`: 实时预览组件
  - `ActionButtons`: 操作按钮（转换、复制、重置）

### 3.2 核心实现逻辑
```javascript
// 零宽字符集
const ZERO_WIDTH_CHARS = {
  // 零宽空格
  SPACE: '\u200B',
  // 零宽非断空格
  NON_BREAKING_SPACE: '\uFEFF',
  // 零宽连字符
  JOINER: '\u200D',
  // 零宽不连字符
  NON_JOINER: '\u200C',
  // 左至右标记
  LEFT_TO_RIGHT_MARK: '\u200E',
  // 右至左标记
  RIGHT_TO_LEFT_MARK: '\u200F'
}

// 将普通文本转换为隐形墨水文本
const encodeToInvisibleInk = (text) => {
  if (!text) return ''
  
  // 将文本转换为二进制字符串
  const binaryText = text.split('').map(char => {
    const binary = char.charCodeAt(0).toString(2)
    // 确保每个字符的二进制表示为8位
    return binary.padStart(8, '0')
  }).join('')
  
  // 将二进制字符串转换为零宽字符
  const invisibleText = binaryText.split('').map(bit => {
    // 使用零宽空格表示0，零宽非断空格表示1
    return bit === '0' ? ZERO_WIDTH_CHARS.SPACE : ZERO_WIDTH_CHARS.NON_BREAKING_SPACE
  }).join('')
  
  return invisibleText
}

// 将隐形墨水文本解码为普通文本
const decodeFromInvisibleInk = (text) => {
  if (!text) return ''
  
  // 提取零宽字符
  const zeroWidthChars = text.split('').filter(char => {
    return Object.values(ZERO_WIDTH_CHARS).includes(char)
  })
  
  // 将零宽字符转换为二进制字符串
  const binaryText = zeroWidthChars.map(char => {
    return char === ZERO_WIDTH_CHARS.SPACE ? '0' : '1'
  }).join('')
  
  // 将二进制字符串转换为普通文本
  let result = ''
  for (let i = 0; i < binaryText.length; i += 8) {
    const byte = binaryText.substr(i, 8)
    if (byte.length === 8) {
      const charCode = parseInt(byte, 2)
      result += String.fromCharCode(charCode)
    }
  }
  
  return result
}

// 复制隐形墨水文本
const copyInvisibleText = async (text) => {
  try {
    await navigator.clipboard.writeText(text)
    return true
  } catch (error) {
    console.error('Failed to copy invisible text:', error)
    return false
  }
}
```
