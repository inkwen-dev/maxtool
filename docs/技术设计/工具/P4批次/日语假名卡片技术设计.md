# 日语假名卡片技术设计文档

## 1. 概述

日语假名卡片是一款帮助用户学习日语假名（平假名和片假名）的在线教育工具。用户可以通过卡片翻转的方式学习假名的发音、书写和含义，支持随机练习和分类练习。

## 2. 功能设计

### 2.1 核心功能
- 显示平假名和片假名卡片
- 支持卡片翻转（显示假名/发音/罗马音）
- 随机练习模式
- 分类练习模式（按行/按发音）
- 进度跟踪功能
- 收藏功能（标记需要重点练习的假名）
- 测试功能（验证学习成果）
- 音频发音功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例
- 学习进度统计

## 3. 技术设计

### 3.1 组件结构
- `KanaFlashcardsTool`: 主组件，包含所有功能
  - `FlashcardDisplay`: 卡片显示组件（支持翻转动画）
  - `ModeSelector`: 模式选择组件（随机/分类）
  - `CategorySelector`: 分类选择组件
  - `ProgressTracker`: 进度跟踪组件
  - `FavoriteControls`: 收藏控制组件
  - `TestMode`: 测试模式组件
  - `AudioPlayer`: 音频播放组件
  - `ActionButtons`: 操作按钮（下一张、翻转、收藏）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 假名数据
const kanaData = {
  hiragana: [
    { id: 1, character: 'あ', romaji: 'a', pronunciation: 'ah', row: 'a', isFavorite: false },
    { id: 2, character: 'い', romaji: 'i', pronunciation: 'ee', row: 'a', isFavorite: false },
    { id: 3, character: 'う', romaji: 'u', pronunciation: 'oo', row: 'a', isFavorite: false },
    { id: 4, character: 'え', romaji: 'e', pronunciation: 'eh', row: 'a', isFavorite: false },
    { id: 5, character: 'お', romaji: 'o', pronunciation: 'oh', row: 'a', isFavorite: false },
    // 更多平假名...
  ],
  katakana: [
    { id: 101, character: 'ア', romaji: 'a', pronunciation: 'ah', row: 'a', isFavorite: false },
    { id: 102, character: 'イ', romaji: 'i', pronunciation: 'ee', row: 'a', isFavorite: false },
    { id: 103, character: 'ウ', romaji: 'u', pronunciation: 'oo', row: 'a', isFavorite: false },
    { id: 104, character: 'エ', romaji: 'e', pronunciation: 'eh', row: 'a', isFavorite: false },
    { id: 105, character: 'オ', romaji: 'o', pronunciation: 'oh', row: 'a', isFavorite: false },
    // 更多片假名...
  ]
}

// 工具状态管理
const [toolState, setToolState] = useState({
  kanaType: 'hiragana', // 默认平假名
  mode: 'random', // 默认随机模式
  category: 'all', // 默认所有分类
  currentCard: null,
  cards: [],
  shuffledCards: [],
  currentIndex: 0,
  isFlipped: false,
  favorites: [],
  progress: { total: 0, learned: 0, correct: 0, wrong: 0 }
})

// 初始化卡片
const initializeCards = () => {
  let cards = [...kanaData[toolState.kanaType]]
  
  // 按分类筛选
  if (toolState.category !== 'all') {
    cards = cards.filter(card => card.row === toolState.category)
  }
  
  // 随机打乱
  const shuffledCards = [...cards].sort(() => Math.random() - 0.5)
  
  setToolState(prev => ({
    ...prev,
    cards,
    shuffledCards,
    currentIndex: 0,
    currentCard: shuffledCards[0],
    isFlipped: false,
    progress: { ...prev.progress, total: cards.length }
  }))
}

// 翻转卡片
const flipCard = () => {
  setToolState(prev => ({ ...prev, isFlipped: !prev.isFlipped }))
}

// 下一张卡片
const nextCard = () => {
  setToolState(prev => {
    const nextIndex = (prev.currentIndex + 1) % prev.shuffledCards.length
    return {
      ...prev,
      currentIndex: nextIndex,
      currentCard: prev.shuffledCards[nextIndex],
      isFlipped: false
    }
  })
}

// 收藏/取消收藏卡片
const toggleFavorite = () => {
  setToolState(prev => {
    if (!prev.currentCard) return prev
    
    const updatedCards = prev.cards.map(card => {
      if (card.id === prev.currentCard.id) {
        return { ...card, isFavorite: !card.isFavorite }
      }
      return card
    })
    
    const updatedShuffledCards = prev.shuffledCards.map(card => {
      if (card.id === prev.currentCard.id) {
        return { ...card, isFavorite: !card.isFavorite }
      }
      return card
    })
    
    const updatedCurrentCard = { ...prev.currentCard, isFavorite: !prev.currentCard.isFavorite }
    
    return {
      ...prev,
      cards: updatedCards,
      shuffledCards: updatedShuffledCards,
      currentCard: updatedCurrentCard,
      favorites: updatedCurrentCard.isFavorite 
        ? [...prev.favorites, updatedCurrentCard.id]
        : prev.favorites.filter(id => id !== updatedCurrentCard.id)
    }
  })
}

// 播放发音
const playPronunciation = async () => {
  if (!toolState.currentCard) return
  
  // 实际项目中可能会调用语音API
  // 这里使用模拟的音频播放
  const audio = new Audio(`/sounds/${toolState.currentCard.romaji}.mp3`)
  await audio.play()
}
```

## 4. 数据结构

```typescript
type KanaType = 'hiragana' | 'katakana'
type PracticeMode = 'random' | 'category'
type KanaCategory = 'all' | 'a' | 'ka' | 'sa' | 'ta' | 'na' | 'ha' | 'ma' | 'ya' | 'ra' | 'wa'

interface KanaCard {
  id: number
  character: string
  romaji: string
  pronunciation: string
  row: KanaCategory
  isFavorite: boolean
}

interface Progress {
  total: number
  learned: number
  correct: number
  wrong: number
}

interface KanaFlashcardsState {
  kanaType: KanaType
  mode: PracticeMode
  category: KanaCategory
  currentCard: KanaCard | null
  cards: KanaCard[]
  shuffledCards: KanaCard[]
  currentIndex: number
  isFlipped: boolean
  favorites: number[]
  progress: Progress
}
```
