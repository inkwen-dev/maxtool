# 文本表情技术设计文档

## 1. 概述

文本表情工具是一款帮助用户浏览、搜索和复制文本表情（Emoticons）的在线工具。文本表情是由普通文本字符组合而成的表情符号，如:)、:D、:(等。

## 2. 功能设计

### 2.1 核心功能
- 显示各种文本表情
- 按类别筛选文本表情
- 搜索特定文本表情
- 文本表情详细信息显示
- 一键复制功能
- 实时预览

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `TextEmoticonsTool`: 主组件，包含所有功能
  - `EmoticonSearch`: 文本表情搜索组件
  - `EmoticonCategories`: 文本表情类别筛选组件
  - `EmoticonGrid`: 文本表情网格展示组件
  - `EmoticonDetails`: 文本表情详细信息组件
  - `ActionButtons`: 操作按钮（复制、搜索）
  - `UsageInstructions`: 使用说明组件

```javascript
// 获取文本表情数据
const getEmoticons = async () => {
  // 实际项目中可能会从API获取文本表情数据
  // 这里使用本地数据模拟
  const emoticons = [
    { id: 1, emoticon: ':)', name: 'smiling face', category: 'face-smiling' },
    { id: 2, emoticon: ':D', name: 'grinning face', category: 'face-smiling' },
    { id: 3, emoticon: ':(', name: 'frowning face', category: 'face-negative' },
    { id: 4, emoticon: ':P', name: 'sticking out tongue', category: 'face-playful' },
    { id: 5, emoticon: ';)\n', name: 'winking face', category: 'face-smiling' },
    { id: 6, emoticon: '<3', name: 'heart', category: 'love' },
    { id: 7, emoticon: '</3', name: 'broken heart', category: 'love' },
    { id: 8, emoticon: 'XD', name: 'laughing face', category: 'face-smiling' },
    // 更多文本表情...
  ]
  return emoticons
}

// 获取文本表情类别
const getEmoticonCategories = async () => {
  // 实际项目中可能会从API获取类别数据
  const categories = [
    { id: 'face-smiling', name: 'Smiling Faces' },
    { id: 'face-negative', name: 'Negative Faces' },
    { id: 'face-playful', name: 'Playful Faces' },
    { id: 'love', name: 'Love & Heart' },
    { id: 'animals', name: 'Animals' },
    { id: 'food', name: 'Food & Drinks' },
    // 更多类别...
  ]
  return categories
}

// 按类别筛选文本表情
const filterEmoticonsByCategory = (emoticons, categoryId) => {
  if (!categoryId) return emoticons
  return emoticons.filter(emoticon => emoticon.category === categoryId)
}

// 搜索文本表情
const searchEmoticons = (emoticons, query) => {
  if (!query) return emoticons
  const lowercaseQuery = query.toLowerCase()
  return emoticons.filter(emoticon => 
    emoticon.name.toLowerCase().includes(lowercaseQuery) ||
    emoticon.emoticon.includes(query)
  )
}

// 复制文本表情
const copyEmoticon = async (emoticon) => {
  try {
    await navigator.clipboard.writeText(emoticon)
    return true
  } catch (error) {
    console.error('Failed to copy emoticon:', error)
    return false
  }
}
```
