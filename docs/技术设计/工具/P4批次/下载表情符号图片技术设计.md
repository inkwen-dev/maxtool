# 下载表情符号图片技术设计文档

## 1. 概述

下载表情符号图片是一款帮助用户下载表情符号为图片文件的在线工具。用户可以选择不同的表情符号，调整大小、颜色等参数，然后将其下载为PNG或SVG格式的图片文件。

## 2. 功能设计

### 2.1 核心功能
- 显示所有表情符号
- 按类别筛选表情符号
- 搜索特定表情符号
- 调整表情符号大小
- 选择图片格式（PNG、SVG）
- 选择图片质量
- 自定义背景颜色
- 实时预览
- 下载功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `DownloadEmojiImagesTool`: 主组件，包含所有功能
  - `EmojiSearch`: 表情符号搜索组件

```javascript
// 获取表情符号数据
const getEmojis = async () => {
  // 实际项目中可能会从API获取表情符号数据
  // 这里使用本地数据模拟
  const emojis = [
    { id: 1, emoji: '😊', name: 'smiling face with smiling eyes', category: 'face-smiling' },
    { id: 2, emoji: '😢', name: 'crying face', category: 'face-negative' },
    { id: 3, emoji: '❤️', name: 'red heart', category: 'heart' },
    { id: 4, emoji: '👍', name: 'thumbs up', category: 'hand-fingers-open' },
    { id: 5, emoji: '🎉', name: 'party popper', category: 'event' },
    // 更多表情符号...
  ]
  return emojis
}

// 获取表情符号类别
const getEmojiCategories = async () => {
  // 实际项目中可能会从API获取类别数据
  const categories = [
    { id: 'face-smiling', name: 'Smiling Faces' },
    { id: 'face-negative', name: 'Negative Faces' },
    { id: 'heart', name: 'Hearts' },
    { id: 'hand-fingers-open', name: 'Open Hands' },
    { id: 'event', name: 'Events' },
    // 更多类别...
  ]
  return categories
}

// 按类别筛选表情符号
const filterEmojisByCategory = (emojis, categoryId) => {
  if (!categoryId) return emojis
  return emojis.filter(emoji => emoji.category === categoryId)
}

// 搜索表情符号
const searchEmojis = (emojis, query) => {
  if (!query) return emojis
  const lowercaseQuery = query.toLowerCase()
  return emojis.filter(emoji => 
    emoji.name.toLowerCase().includes(lowercaseQuery) ||
    emoji.emoji.includes(query)
  )
}

// 将表情符号转换为图片并下载
const downloadEmojiAsImage = async (emoji, options) => {
  const { size, format, quality, backgroundColor } = options
  
  // 创建Canvas元素
  const canvas = document.createElement('canvas')
  canvas.width = size
  canvas.height = size
  
  // 获取Canvas上下文
  const ctx = canvas.getContext('2d')
  
  // 设置背景颜色
  ctx.fillStyle = backgroundColor
  ctx.fillRect(0, 0, size, size)
  
  // 设置文本样式
  ctx.font = `${size * 0.8}px Arial`
  ctx.textAlign = 'center'
  ctx.textBaseline = 'middle'
  ctx.fillStyle = '#000000'
  
  // 绘制表情符号
  ctx.fillText(emoji, size / 2, size / 2)
  
  // 转换为图片并下载
  if (format === 'png') {
    canvas.toBlob(blob => {
      const url = URL.createObjectURL(blob)
      const a = document.createElement('a')
      a.href = url
      a.download = `${emoji}-${size}x${size}.png`
      a.click()
      URL.revokeObjectURL(url)
    }, 'image/png', quality)
  } else if (format === 'svg') {
    // 创建SVG元素
    const svg = document.createElementNS('http://www.w3.org/2000/svg', 'svg')
    svg.setAttribute('width', size)
    svg.setAttribute('height', size)
    svg.setAttribute('xmlns', 'http://www.w3.org/2000/svg')
    
    // 创建矩形作为背景
    const rect = document.createElementNS('http://www.w3.org/2000/svg', 'rect')
    rect.setAttribute('width', '100%')
    rect.setAttribute('height', '100%')
    rect.setAttribute('fill', backgroundColor)
    svg.appendChild(rect)
    
    // 创建文本元素
    const text = document.createElementNS('http://www.w3.org/2000/svg', 'text')
    text.setAttribute('x', '50%')
    text.setAttribute('y', '50%')
    text.setAttribute('font-family', 'Arial')
    text.setAttribute('font-size', `${size * 0.8}`)
    text.setAttribute('text-anchor', 'middle')
    text.setAttribute('dominant-baseline', 'middle')
    text.setAttribute('fill', '#000000')
    text.textContent = emoji
    svg.appendChild(text)
    
    // 将SVG转换为字符串
    const svgString = new XMLSerializer().serializeToString(svg)
    
    // 创建Blob并下载
    const blob = new Blob([svgString], { type: 'image/svg+xml' })
    const url = URL.createObjectURL(blob)
    const a = document.createElement('a')
    a.href = url
    a.download = `${emoji}-${size}x${size}.svg`
    a.click()
    URL.revokeObjectURL(url)
  }
}
```
