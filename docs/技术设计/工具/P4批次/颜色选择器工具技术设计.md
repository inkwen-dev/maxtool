# 颜色选择器工具技术设计文档

## 1. 概述

颜色选择器工具是一款帮助用户选择和调整颜色的在线工具。用户可以通过多种方式选择颜色（RGB、HEX、HSL、色相环），并获得相应的颜色代码和预览效果。

## 2. 功能设计

### 2.1 核心功能
- 多种颜色选择方式（RGB、HEX、HSL、色相环）
- 颜色值实时转换（RGB ↔ HEX ↔ HSL）
- 颜色预览（单色、渐变）
- 颜色历史记录
- 复制颜色代码功能
- 颜色对比度检查

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `ColorPicker`: 主组件，包含所有功能
  - `HueSlider`: 色相选择滑块
  - `SaturationBrightnessPicker`: 饱和度和亮度选择器
  - `ColorInputs`: 颜色值输入组件（RGB、HEX、HSL）
  - `ColorPreview`: 颜色预览组件
  - `ColorHistory`: 颜色历史记录组件
  - `ContrastChecker`: 颜色对比度检查组件
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 颜色转换函数
const hexToRgb = (hex) => {
  // 移除#符号
  hex = hex.replace(/^#/, '')
  
  // 解析RGB值
  let r, g, b
  if (hex.length === 3) {
    // 简写形式（如#RGB）
    r = parseInt(hex.charAt(0) + hex.charAt(0), 16)
    g = parseInt(hex.charAt(1) + hex.charAt(1), 16)
    b = parseInt(hex.charAt(2) + hex.charAt(2), 16)
  } else {
    // 完整形式（如#RRGGBB）
    r = parseInt(hex.substring(0, 2), 16)
    g = parseInt(hex.substring(2, 4), 16)
    b = parseInt(hex.substring(4, 6), 16)
  }
  
  return { r, g, b }
}

const rgbToHex = (r, g, b) => {
  return '#' + [r, g, b].map(x => {
    const hex = x.toString(16)
    return hex.length === 1 ? '0' + hex : hex
  }).join('')
}

const rgbToHsl = (r, g, b) => {
  r /= 255
  g /= 255
  b /= 255
  
  const max = Math.max(r, g, b)
  const min = Math.min(r, g, b)
  let h, s, l = (max + min) / 2
  
  if (max === min) {
    h = s = 0 // 灰色
  } else {
    const d = max - min
    s = l > 0.5 ? d / (2 - max - min) : d / (max + min)
    
    switch (max) {
      case r: h = (g - b) / d + (g < b ? 6 : 0); break
      case g: h = (b - r) / d + 2; break
      case b: h = (r - g) / d + 4; break
    }
    
    h /= 6
  }
  
  return {
    h: Math.round(h * 360),
    s: Math.round(s * 100),
    l: Math.round(l * 100)
  }
}

// 计算颜色对比度
const calculateContrast = (color1, color2) => {
  const getLuminance = (r, g, b) => {
    const [R, G, B] = [r, g, b].map(x => {
      x /= 255
      return x <= 0.03928 ? x / 12.92 : Math.pow((x + 0.055) / 1.055, 2.4)
    })
    return 0.2126 * R + 0.7152 * G + 0.0722 * B
  }
  
  const { r: r1, g: g1, b: b1 } = color1
  const { r: r2, g: g2, b: b2 } = color2
  
  const l1 = getLuminance(r1, g1, b1)
  const l2 = getLuminance(r2, g2, b2)
  
  const brightest = Math.max(l1, l2)
  const darkest = Math.min(l1, l2)
  
  return (brightest + 0.05) / (darkest + 0.05)
}
```
