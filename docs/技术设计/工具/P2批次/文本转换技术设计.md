# 文本转换技术设计文档

## 1. 概述

文本转换工具是一款帮助用户快速转换文本大小写格式的在线文本处理工具。用户可以输入文本，选择不同的转换选项（如大写、小写、首字母大写等），实时查看转换结果。

## 2. 功能设计

### 2.1 核心功能
- 文本输入区域
- 多种转换选项：
  - 全部大写
  - 全部小写
  - 首字母大写（每个单词）
  - 句子首字母大写
  - 切换大小写
  - 标题大小写（每个主要单词首字母大写）
  - 去除多余空格
  - 反转文本
- 实时转换结果预览
- 复制转换结果功能
- 清空输入功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例
- 字符数统计功能

## 3. 技术设计

### 3.2 核心实现逻辑
```javascript
// 文本转换函数
const transformText = (text, transformationType) => {
  if (!text) return ''
  
  switch (transformationType) {
    case 'uppercase':
      return text.toUpperCase()
    
    case 'lowercase':
      return text.toLowerCase()
    
    case 'capitalize':
      return text.replace(/\b\w/g, char => char.toUpperCase())
    
    case 'sentenceCase':
      return text.replace(/(^|[.!?]\\s+)([a-z])/g, (match, separator, char) => separator + char.toUpperCase())
    
    case 'toggleCase':
      return text.split('').map(char => {
        return char === char.toUpperCase() ? char.toLowerCase() : char.toUpperCase()
      }).join('')
    
    case 'titleCase':
      // 排除冠词、介词、连词等小词
      const smallWords = /\\b(a|an|the|and|but|or|for|nor|on|at|to|from|by)\\b/gi
      return text.replace(/\b\w/g, (char, index, text) => {
        // 如果是第一个单词，大写
        if (index === 0) return char.toUpperCase()
        
        // 检查前一个单词是否是小词
        const prevWord = text.substring(0, index).match(/\w+$/)
        if (prevWord && smallWords.test(prevWord[0])) {
          // 检查是否是句子的第一个单词
          const beforePrevWord = text.substring(0, index - prevWord[0].length)
          if (beforePrevWord.match(/[.!?]\\s*$/)) {
            return char.toUpperCase()
          }
          return char.toLowerCase()
        }
        
        return char.toUpperCase()
      })
    
    case 'removeExtraSpaces':
      return text.replace(/\s+/g, ' ').trim()
    
    case 'reverse':
      return text.split('').reverse().join('')
    
    default:
      return text
  }
}

// 工具状态管理
const [toolState, setToolState] = useState({
  inputText: '',
  selectedTransformation: 'uppercase',
  outputText: '',
  isTransforming: false
})

// 处理输入文本变化
const handleInputTextChange = (e) => {
  const inputText = e.target.value
  setToolState(prev => ({
    ...prev,
    inputText,
    outputText: transformText(inputText, prev.selectedTransformation)
  }))
}

// 处理转换选项变化
const handleTransformationChange = (transformationType) => {
  setToolState(prev => ({
    ...prev,
    selectedTransformation: transformationType,
    outputText: transformText(prev.inputText, transformationType)
  }))
}

// 复制转换结果
const copyResult = () => {
  if (!toolState.outputText) return
  
  navigator.clipboard.writeText(toolState.outputText)
    .then(() => {
      // 显示复制成功提示
      // 实际实现中会有提示组件
    })
    .catch(err => {
      console.error('复制失败:', err)
      // 显示复制失败提示
    })
}

// 清空输入
const clearInput = () => {
  setToolState({
    inputText: '',
    selectedTransformation: 'uppercase',
    outputText: '',
    isTransforming: false
  })
}

// 转换选项配置
const transformationOptions = [

  { id: 'capitalize', name: '首字母大写', description: '将每个单词的首字母转换为大写' },
  { id: 'sentenceCase', name: '句子首字母大写', description: '将每个句子的首字母转换为大写' },
  { id: 'titleCase', name: '标题大小写', description: '将每个主要单词的首字母转换为大写' },
  { id: 'toggleCase', name: '切换大小写', description: '切换每个字符的大小写' },
  { id: 'removeExtraSpaces', name: '去除多余空格', description: '去除文本中的多余空格' },
```
