# 时区转换器技术设计文档

## 1. 概述

时区转换器是一款帮助用户在不同时区之间转换时间的在线工具。用户可以输入一个时间，选择源时区和目标时区，获取转换后的时间，并查看相关的时区信息。

## 2. 功能设计

### 2.1 核心功能
- 支持全球主要时区转换
- 实时时间转换
- 双向转换（源到目标，目标到源）
- 日期和时间选择器
- 时区信息显示（当前时间、UTC偏移）

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `TimeZoneConverter`: 主组件，包含所有功能
  - `DateTimeInput`: 日期和时间输入组件
  - `SourceTimeZoneSelector`: 源时区选择组件
  - `TargetTimeZoneSelector`: 目标时区选择组件
  - `ConversionResult`: 转换结果显示组件
  - `ActionButtons`: 操作按钮（交换时区、复制结果）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 时区转换
const convertTimeZone = (date, sourceTimeZone, targetTimeZone) => {
  try {
    // 使用Intl.DateTimeFormat进行时区转换
    const sourceFormatter = new Intl.DateTimeFormat('en-US', {
      timeZone: sourceTimeZone,
      year: 'numeric',
      month: '2-digit',
      day: '2-digit',
      hour: '2-digit',
      minute: '2-digit',
      second: '2-digit'
    })
    
    const targetFormatter = new Intl.DateTimeFormat('en-US', {
      timeZone: targetTimeZone,
      year: 'numeric',
      month: '2-digit',
      day: '2-digit',
      hour: '2-digit',
      minute: '2-digit',
      second: '2-digit'
    })
    
    // 获取源时区的时间字符串
    const sourceTimeString = sourceFormatter.format(date)
    
    // 创建源时区的Date对象
    const sourceDate = new Date(`${sourceTimeString} ${sourceTimeZone}`)
    
    // 转换为目标时区
    const targetDate = new Date(sourceDate.toLocaleString('en-US', {
      timeZone: targetTimeZone
    }))
    
    return targetDate
  } catch (error) {
    throw new Error('Time zone conversion failed')
  }
}

// 获取时区列表
const getTimeZones = () => {
  // 实际实现中可以使用Intl.supportedValuesOf('timeZone')获取支持的时区列表
  return [
    'UTC',
    'Asia/Shanghai',
    'Asia/Tokyo',
    'Asia/Singapore',
    'Europe/London',
    'Europe/Paris',
    'America/New_York',
    'America/Los_Angeles',
    // 更多时区...
  ]
}

// 获取时区的UTC偏移
const getUtcOffset = (timeZone) => {
  const now = new Date()
  const formatter = new Intl.DateTimeFormat('en-US', {
    timeZone: timeZone,
    timeZoneName: 'shortOffset'
  })
  
  const parts = formatter.formatToParts(now)
  const offsetPart = parts.find(part => part.type === 'timeZoneName')
  
  return offsetPart ? offsetPart.value : ''
}
```
