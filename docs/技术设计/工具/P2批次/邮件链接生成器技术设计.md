# 邮件链接生成器技术设计文档

## 1. 概述

邮件链接生成器是一款帮助用户创建美观、功能丰富的邮件HTML链接的在线工具。用户可以输入邮件地址、主题、正文等信息，工具会生成对应的HTML代码，用户可以直接复制到网页中使用。

## 2. 功能设计

### 2.1 核心功能
- 输入邮件地址
- 设置邮件主题
- 设置邮件正文
- 设置链接文本
- 选择链接样式
- 生成HTML代码
- 实时预览效果
- 复制生成的HTML代码

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例
- 代码格式化功能

## 3. 技术设计

### 3.1 组件结构
- `EmailLinkGeneratorTool`: 主组件，包含所有功能
  - `EmailForm`: 邮件信息表单组件
  - `StyleSelector`: 样式选择组件
  - `HTMLPreview`: HTML代码预览组件
  - `LinkPreview`: 链接效果预览组件
  - `ActionButtons`: 操作按钮（复制代码、生成）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 工具状态管理
const [toolState, setToolState] = useState({
  email: '',
  subject: '',
  body: '',
  linkText: 'Send Email',
  style: 'default',
  htmlCode: ''
})

// 预设样式
const styles = {
  default: {
    css: 'color: #0066cc; text-decoration: none;',
    className: ''
  },
  button: {
    css: 'background-color: #0066cc; color: white; padding: 8px 16px; border-radius: 4px; text-decoration: none;',
    className: 'email-button'
  },
  underlined: {
    css: 'color: #0066cc; text-decoration: underline;',
    className: 'email-link-underlined'
  },
  bold: {
    css: 'color: #0066cc; font-weight: bold; text-decoration: none;',
    className: 'email-link-bold'
  }
}

// 生成邮件链接HTML代码
const generateEmailLink = () => {
  const { email, subject, body, linkText, style } = toolState
  
  // 构建mailto链接
  let mailtoLink = `mailto:${encodeURIComponent(email)}`
  
  // 添加主题
  if (subject) {
    mailtoLink += `?subject=${encodeURIComponent(subject)}`
  }
  
  // 添加正文
  if (body) {
    const separator = subject ? '&' : '?'
    mailtoLink += `${separator}body=${encodeURIComponent(body)}`
  }
  
  // 获取样式
  const selectedStyle = styles[style] || styles.default
  
  // 生成HTML代码
  let htmlCode = `<a href="${mailtoLink}" style="${selectedStyle.css}"`
  
  if (selectedStyle.className) {
    htmlCode += ` class="${selectedStyle.className}"`
  }
  
  htmlCode += `>${linkText}</a>`
  
  // 更新状态
  setToolState(prev => ({
    ...prev,
    htmlCode
  }))
  
  return htmlCode
}

// 复制HTML代码
const copyHtmlCode = async () => {
  try {
    await navigator.clipboard.writeText(toolState.htmlCode)
    return true
  } catch (error) {
    console.error('Failed to copy HTML code:', error)
    return false
  }
}
```

### 3.3 组件复用
- `Button`: 通用按钮组件
- `Input`: 输入组件（邮件地址、主题、正文、链接文本）
- `Select`: 选择组件（样式）
- `Textarea`: 文本区域组件（HTML预览）
- `UsageInstructions`: 使用说明组件

### 3.4 工具函数复用
- `copyToClipboard`: 复制功能
- `trackUsage`: 工具使用统计
