# 进制转换器技术设计文档

## 一、概述

本文档详细描述MaxTool 0.2版本中进制转换器（Base Converter）工具的技术设计，包括功能设计、技术实现、组件结构和代码复用等方面。设计严格遵循项目规范，注重代码复用、组件化和性能优化。

## 二、功能设计

### 1. 核心功能

#### 进制转换
- 支持多种进制之间的转换
- 支持常用进制：二进制（2）、八进制（8）、十进制（10）、十六进制（16）
- 支持自定义进制（2-36进制）

#### 高级功能
- 批量转换：支持同时转换多个数值
- 历史记录：保存最近的转换记录
- 格式化输出：支持不同格式的输出（如添加前缀、分隔符）

### 2. 用户界面

#### 转换设置区域
- 输入数值：用于输入要转换的数值
- 输入进制选择：选择输入数值的进制
- 输出进制选择：选择要转换到的进制（支持多选）
- 批量输入区域：用于批量转换

#### 转换结果区域
- 显示转换结果
- 提供复制结果功能

#### 历史记录区域
- 显示最近的转换记录
- 支持清除历史记录

#### 使用说明
- 提供简洁的使用步骤说明

## 三、技术设计

### 1. 技术选型

#### 核心库
- 原生JavaScript：用于进制转换的核心逻辑

#### 浏览器API
- Clipboard API：用于复制转换结果
- LocalStorage API：用于保存历史记录

### 2. 组件结构

#### 主组件

##### BaseConverter
- **位置**：`components/tools/BaseConverter.tsx`
- **功能**：进制转换器工具的主组件
- **结构**：
  ```tsx
  'use client'

  import { useState, useEffect } from 'react'
  import Button from '@/components/ui/Button'
  import Input from '@/components/ui/Input'
  import Textarea from '@/components/ui/Textarea'
  import { trackUsage } from '@/lib/tracking'
  import UsageInstructions from '@/components/shared/UsageInstructions'
  import { copyToClipboard } from '@/lib/clipboard-utils'

  // 定义常用进制
  const COMMON_BASES = [2, 8, 10, 16]

  // 定义转换记录
  interface ConversionRecord {
    id: string
    inputValue: string
    inputBase: number
    outputValues: { [base: number]: string }
    timestamp: Date
  }

  export default function BaseConverter() {
    // State declarations
    const [inputValue, setInputValue] = useState<string>('')
    const [inputBase, setInputBase] = useState<number>(10)
    const [outputBases, setOutputBases] = useState<number[]>([2, 16])
    const [customOutputBase, setCustomOutputBase] = useState<number>(10)
    const [showCustomBaseInput, setShowCustomBaseInput] = useState<boolean>(false)
    const [batchInput, setBatchInput] = useState<string>('')
    const [batchResults, setBatchResults] = useState<{ [value: string]: { [base: number]: string } } | null>(null)
    const [results, setResults] = useState<{ [base: number]: string }>({})
    const [error, setError] = useState<string | null>(null)
    const [history, setHistory] = useState<ConversionRecord[]>([])
    const [showHistory, setShowHistory] = useState<boolean>(false)
    const [hasTracked, setHasTracked] = useState(false)

    // 初始化
    useEffect(() => {
      trackUsage('base-converter')
      setHasTracked(true)
      loadHistory()
    }, [])

    // 加载历史记录
    const loadHistory = () => {
      const savedHistory = localStorage.getItem('baseConverterHistory')
      if (savedHistory) {
        try {
          const parsedHistory = JSON.parse(savedHistory).map((record: any) => ({
            ...record,
            timestamp: new Date(record.timestamp)
          }))
          setHistory(parsedHistory)
        } catch (err) {
          console.error('Failed to load history:', err)
          localStorage.removeItem('baseConverterHistory')
        }
      }
    }

    // 保存历史记录
    const saveHistory = (record: ConversionRecord) => {
      const updatedHistory = [record, ...history.slice(0, 9)].filter((item, index, self) => 
        index === self.findIndex((t) => t.inputValue === item.inputValue && t.inputBase === item.inputBase)
      )
      setHistory(updatedHistory)
      localStorage.setItem('baseConverterHistory', JSON.stringify(updatedHistory))
    }

    // 清除历史记录
    const clearHistory = () => {
      setHistory([])
      localStorage.removeItem('baseConverterHistory')
    }

    // 转换数值
    const convertValue = () => {
      if (!inputValue.trim()) {
        setResults({})
        setError(null)
        return
      }

      try {
        setError(null)
        const decimalValue = parseInt(inputValue.trim(), inputBase)

        if (isNaN(decimalValue)) {
          throw new Error(`输入的值不是有效的${inputBase}进制数`)
        }

        const conversionResults: { [base: number]: string } = {}

        outputBases.forEach(base => {
          conversionResults[base] = decimalValue.toString(base).toUpperCase()
        })

        setResults(conversionResults)

        // 保存到历史记录
        const record: ConversionRecord = {
          id: Date.now().toString(),
          inputValue: inputValue.trim(),
          inputBase,
          outputValues: conversionResults,
          timestamp: new Date()
        }
        saveHistory(record)
      } catch (err) {
        setError(err instanceof Error ? err.message : '转换失败')
        setResults({})
      }
    }

    // 批量转换
    const batchConvert = () => {
      if (!batchInput.trim()) {
        setBatchResults(null)
        setError(null)
        return
      }

      try {
        setError(null)
        const values = batchInput.trim().split(/\s+/)
        const batchConversionResults: { [value: string]: { [base: number]: string } } = {}

        values.forEach(value => {
          const decimalValue = parseInt(value, inputBase)
          if (!isNaN(decimalValue)) {
            const results: { [base: number]: string } = {}
            outputBases.forEach(base => {
              results[base] = decimalValue.toString(base).toUpperCase()
            })
            batchConversionResults[value] = results
          } else {
            batchConversionResults[value] = { error: `${value}不是有效的${inputBase}进制数` }
          }
        })

        setBatchResults(batchConversionResults)
      } catch (err) {
        setError(err instanceof Error ? err.message : '批量转换失败')
        setBatchResults(null)
      }
    }

    // 复制结果
    const copyResult = (value: string) => {
      copyToClipboard(value)
      // 显示复制成功提示
    }

    // 复制所有结果
    const copyAllResults = () => {
      const resultText = Object.entries(results)
        .map(([base, value]) => `${base}进制: ${value}`)
        .join('\n')
      copyToClipboard(resultText)
      // 显示复制成功提示
    }

    // 添加自定义输出进制
    const addCustomOutputBase = () => {
      if (customOutputBase >= 2 && customOutputBase <= 36 && !outputBases.includes(customOutputBase)) {
        setOutputBases(prev => [...prev, customOutputBase])
        setCustomOutputBase(10)
        setShowCustomBaseInput(false)
      }
    }

    // 移除输出进制
    const removeOutputBase = (base: number) => {
      setOutputBases(prev => prev.filter(b => b !== base))
    }

    // Event handlers
    const handleInputChange = (e: React.ChangeEvent<HTMLInputElement>) => {
      setInputValue(e.target.value)
    }

    const handleInputBaseChange = (e: React.ChangeEvent<HTMLSelectElement>) => {
      setInputBase(parseInt(e.target.value))
    }

    const handleOutputBaseToggle = (base: number) => {
      setOutputBases(prev => {
        if (prev.includes(base)) {
          return prev.filter(b => b !== base)
        } else {
          return [...prev, base].sort((a, b) => a - b)
        }
      })
    }

    // 应用历史记录
    const applyHistoryRecord = (record: ConversionRecord) => {
      setInputValue(record.inputValue)
      setInputBase(record.inputBase)
      setOutputBases(Object.keys(record.outputValues).map(base => parseInt(base)).sort((a, b) => a - b))
      setResults(record.outputValues)
      setBatchResults(null)
      setError(null)
    }

    // 监听输入变化，自动转换
    useEffect(() => {
      convertValue()
    }, [inputValue, inputBase, outputBases])

    // Render
    return (
      <div className="space-y-6">
        {/* Header */}
        <div className="space-y-4">
          <h2 className="text-xl font-semibold">进制转换器</h2>
        </div>

        {/* Input Section */}
        <div className="space-y-6">
          <div className="space-y-4">
            <h3 className="text-lg font-semibold">转换设置</h3>
            
            <div className="grid grid-cols-2 gap-4">
              {/* Input Value */}
              <div className="space-y-2">
                <label htmlFor="inputValue">输入数值</label>
                <Input
                  id="inputValue"
                  value={inputValue}
                  onChange={handleInputChange}
                  placeholder={`输入${inputBase}进制数`}
                />
              </div>
              
              {/* Input Base */}
              <div className="space-y-2">
                <label htmlFor="inputBase">输入进制</label>
                <select
                  id="inputBase"
                  value={inputBase}
                  onChange={handleInputBaseChange}
                  className="w-full p-2 border rounded"
                >
                  {COMMON_BASES.map(base => (
                    <option key={base} value={base}>{base}进制</option>
                  ))}
                  <optgroup label="自定义">
                    {[...Array(27)].map((_, i) => i + 2).filter(base => !COMMON_BASES.includes(base)).map(base => (
                      <option key={base} value={base}>{base}进制</option>
                    ))}
                  </optgroup>
                </select>
              </div>
            </div>
          </div>
          
          {/* Output Bases */}
          <div className="space-y-4">
            <h3 className="text-lg font-semibold">输出进制</h3>
            
            <div className="grid grid-cols-4 gap-4">
              {COMMON_BASES.map(base => (
                <div key={base} className="flex items-center space-x-2">
                  <input
                    type="checkbox"
                    id={`outputBase${base}`}
                    checked={outputBases.includes(base)}
                    onChange={() => handleOutputBaseToggle(base)}
                  />
                  <label htmlFor={`outputBase${base}`}>{base}进制</label>
                </div>
              ))}
            </div>
            
            {/* Custom Output Base */}
            <div className="space-y-2">
              {showCustomBaseInput ? (
                <div className="flex space-x-2">
                  <div className="flex-1">
                    <input
                      type="number"
                      min="2"
                      max="36"
                      value={customOutputBase}
                      onChange={(e) => setCustomOutputBase(parseInt(e.target.value) || 10)}
                      className="w-full p-2 border rounded"
                      placeholder="2-36"
                    />
                  </div>
                  <div className="flex space-x-2">
                    <Button onClick={addCustomOutputBase} variant="primary" size="sm">
                      添加
                    </Button>
                    <Button onClick={() => setShowCustomBaseInput(false)} variant="secondary" size="sm">
                      取消
                    </Button>
                  </div>
                </div>
              ) : (
                <Button onClick={() => setShowCustomBaseInput(true)} variant="secondary" size="sm">
                  添加自定义进制
                </Button>
              )}
            </div>
            
            {/* Current Output Bases */}
            {outputBases.length > 0 && (
              <div className="flex flex-wrap gap-2">
                {outputBases.map(base => (
                  <div key={base} className="flex items-center space-x-1 bg-bg-secondary px-3 py-1 rounded-full">
                    <span>{base}进制</span>
                    <button
                      onClick={() => removeOutputBase(base)}
                      className="text-text-tertiary hover:text-text-primary"
                    >
                      ×
                    </button>
                  </div>
                ))}
              </div>
            )}
          </div>
        </div>

        {/* Batch Input */}
        <div className="space-y-4">
          <h3 className="text-lg font-semibold">批量转换</h3>
          <Textarea
            value={batchInput}
            onChange={(e) => setBatchInput(e.target.value)}
            placeholder="输入多个数值，用空格或换行分隔..."
            className="min-h-[100px]"
          />
          <div className="flex justify-end">
            <Button onClick={batchConvert} disabled={!batchInput.trim()} variant="primary" size="sm">
              批量转换
            </Button>
          </div>
        </div>

        {/* Error Message */}
        {error && (
          <div className="p-2 bg-red-50 border border-red-200 rounded text-red-700">
            {error}
          </div>
        )}

        {/* Results */}
        <div className="space-y-6">
          {/* Single Result */}
          {Object.keys(results).length > 0 && (
            <div className="space-y-4">
              <div className="flex justify-between items-center">
                <h3 className="text-lg font-semibold">转换结果</h3>
                <Button onClick={copyAllResults} variant="secondary" size="sm">
                  复制所有
                </Button>
              </div>
              
              <div className="grid grid-cols-1 md:grid-cols-2 gap-4">
                {Object.entries(results).map(([base, value]) => (
                  <div key={base} className="flex justify-between items-center p-3 border border-border-secondary bg-bg-secondary rounded-lg">
                    <div>
                      <div className="text-sm text-text-secondary">{base}进制</div>
                      <div className="text-lg font-medium">{value}</div>
                    </div>
                    <Button onClick={() => copyResult(value)} variant="secondary" size="sm">
                      复制
                    </Button>
                  </div>
                ))}
              </div>
            </div>
          )}
          
          {/* Batch Results */}
          {batchResults && Object.keys(batchResults).length > 0 && (
            <div className="space-y-4">
              <h3 className="text-lg font-semibold">批量转换结果</h3>
              
              <div className="overflow-x-auto">
                <table className="min-w-full border-collapse">
                  <thead>
                    <tr className="border-b">
                      <th className="px-4 py-2 text-left">输入值</th>
                      {outputBases.map(base => (
                        <th key={base} className="px-4 py-2 text-left">{base}进制</th>
                      ))}
                    </tr>
                  </thead>
                  <tbody>
                    {Object.entries(batchResults).map(([inputValue, results]) => (
                      <tr key={inputValue} className="border-b">
                        <td className="px-4 py-2">{inputValue}</td>
                        {outputBases.map(base => (
                          <td key={base} className="px-4 py-2">
                            {results[base] ? (
                              <div className="flex items-center space-x-2">
                                <span>{results[base]}</span>
                                <Button onClick={() => copyResult(results[base])} variant="secondary" size="sm">
                                  复制
                                </Button>
                              </div>
                            ) : (
                              <span className="text-red-500">错误</span>
                            )}
                          </td>
                        ))}
                      </tr>
                    ))}
                  </tbody>
                </table>
              </div>
            </div>
          )}
        </div>

        {/* History */}
        <div className="space-y-4">
          <div className="flex justify-between items-center">
            <button
              className="text-lg font-semibold"
              onClick={() => setShowHistory(!showHistory)}
            >
              历史记录 {history.length > 0 && `(${history.length})`}
            </button>
            {history.length > 0 && (
              <Button onClick={clearHistory} variant="secondary" size="sm">
                清空
              </Button>
            )}
          </div>
          
          {showHistory && history.length > 0 && (
            <div className="p-4 border border-border-secondary bg-bg-secondary rounded-lg max-h-[300px] overflow-auto">
              <div className="space-y-3">
                {history.map((record) => (
                  <div key={record.id} className="p-3 border border-border-tertiary rounded-lg hover:bg-bg-tertiary cursor-pointer" onClick={() => applyHistoryRecord(record)}>
                    <div className="flex justify-between items-center text-sm">
                      <span className="text-text-secondary">
                        {record.inputBase}进制: {record.inputValue}
                      </span>
                      <span className="text-text-tertiary">
                        {record.timestamp.toLocaleString('zh-CN')}
                      </span>
                    </div>
                    <div className="mt-1 text-sm">
                      {Object.entries(record.outputValues)
                        .slice(0, 2)
                        .map(([base, value]) => `${base}进制: ${value}`)
                        .join(', ')}
                      {Object.keys(record.outputValues).length > 2 && '...'}
                    </div>
                  </div>
                ))}
              </div>
            </div>
          )}
          
          {showHistory && history.length === 0 && (
            <div className="p-4 border border-border-secondary bg-bg-secondary rounded-lg text-text-secondary">
              暂无历史记录
            </div>
          )}
        </div>

        {/* Usage Instructions */}
        <UsageInstructions
          items={[
            '在输入框中输入要转换的数值',
            '选择输入数值的进制（默认十进制）',
            '选择要转换到的输出进制（可多选）',
            '可以添加自定义进制（2-36之间）',
            '输入完成后，转换结果会自动显示',
            '使用批量转换功能可以同时转换多个数值',
            '历史记录会保存最近的转换操作'
          ]}
        />
      </div>
    )
  }
  ```

## 三、技术实现

### 1. 进制转换实现

使用JavaScript的内置方法实现进制转换：

```typescript
// 将数值从一个进制转换到另一个进制
const convertBase = (value: string, fromBase: number, toBase: number): string => {
  const decimalValue = parseInt(value, fromBase)
  if (isNaN(decimalValue)) {
    throw new Error(`Invalid ${fromBase} base number: ${value}`)
  }
  return decimalValue.toString(toBase).toUpperCase()
}
```

  }
}

## 四、性能优化

### 1. 计算优化

- 使用JavaScript内置的进制转换方法，性能高效
- 避免不必要的重复计算
