# 文本加密解密工具技术设计文档

## 1. 概述

文本加密解密工具是一款帮助用户加密和解密文本的在线工具。用户可以选择不同的加密算法，输入密钥和文本，进行加密或解密操作。

## 2. 功能设计

### 2.1 核心功能
- 支持多种加密算法（AES、DES、Base64等）
- 加密和解密双向操作
- 密钥生成和管理
- 实时预览
- 复制和下载功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `TextEncryptionTool`: 主组件，包含所有功能
  - `AlgorithmSelector`: 加密算法选择组件
  - `KeyInput`: 密钥输入组件
  - `TextInput`: 文本输入组件
  - `TextPreview`: 实时预览组件
  - `ActionButtons`: 操作按钮（加密、解密、生成密钥、复制、下载）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// Base64加密
const base64Encrypt = (text) => {
  try {
    return btoa(encodeURIComponent(text))
  } catch (error) {
    throw new Error('Base64 encryption failed')
  }
}

// Base64解密
const base64Decrypt = (text) => {
  try {
    return decodeURIComponent(atob(text))
  } catch (error) {
    throw new Error('Base64 decryption failed')
  }
}

// 简单的恺撒密码加密
const caesarEncrypt = (text, shift = 3) => {
  return text.replace(/[a-zA-Z]/g, (char) => {
    const isUpperCase = char === char.toUpperCase()
    const baseCharCode = isUpperCase ? 'A'.charCodeAt(0) : 'a'.charCodeAt(0)
    return String.fromCharCode(((char.charCodeAt(0) - baseCharCode + shift) % 26) + baseCharCode)
  })
}

// 简单的恺撒密码解密
const caesarDecrypt = (text, shift = 3) => {
  return caesarEncrypt(text, 26 - shift)
}

// 生成随机密钥
const generateKey = (length = 16) => {
  const chars = 'ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789!@#$%^&*()_+-=[]{}|;:,.<>?'
  let key = ''
  for (let i = 0; i < length; i++) {
    key += chars.charAt(Math.floor(Math.random() * chars.length))
  }
  return key
}
```
