# 删除线文本生成器技术设计文档

## 1. 概述

删除线文本生成器是一款帮助用户为文本添加删除线格式的在线工具。用户可以输入或粘贴文本，工具会自动为文本添加删除线格式，并提供多种输出格式选项（如HTML、Markdown、Unicode等）。

## 2. 功能设计

### 2.1 核心功能
- 为文本添加删除线格式
- 支持多种输出格式（HTML、Markdown、Unicode）
- 批量处理多行文本
- 实时预览
- 复制功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `StrikethroughGeneratorTool`: 主组件，包含所有功能
  - `TextInput`: 文本输入组件
  - `FormatSelector`: 输出格式选择组件
  - `TextPreview`: 实时预览组件
  - `ActionButtons`: 操作按钮（生成、复制、重置）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 为文本添加删除线（HTML格式）
const addStrikethroughHtml = (text) => {
  return `<del>${text}</del>`
}

// 为文本添加删除线（Markdown格式）
const addStrikethroughMarkdown = (text) => {
  return `~~${text}~~`
}

// 为文本添加删除线（Unicode格式）
const addStrikethroughUnicode = (text) => {
  // 使用Unicode删除线字符（U+0336）
  return text.split('').map(char => char + '\u0336').join('')
}

// 批量处理多行文本
const processMultipleLines = (text, formatFunction) => {
  return text.split('\n').map(line => formatFunction(line)).join('\n')
}

// 生成删除线文本
const generateStrikethrough = (text, format) => {
  if (!text) return ''
  
  let formattedText = ''
  
  switch (format) {
    case 'html':
      formattedText = addStrikethroughHtml(text)
      break
    case 'markdown':
      formattedText = addStrikethroughMarkdown(text)
      break
    case 'unicode':
      formattedText = addStrikethroughUnicode(text)
      break
    default:
      formattedText = addStrikethroughHtml(text)
  }
  
  return formattedText
}

// 批量生成删除线文本
const generateStrikethroughBatch = (text, format) => {
  if (!text) return ''
  
  let formattedText = ''
  
  switch (format) {
    case 'html':
      formattedText = processMultipleLines(text, addStrikethroughHtml)
      break
    case 'markdown':
      formattedText = processMultipleLines(text, addStrikethroughMarkdown)
      break
    case 'unicode':
      formattedText = processMultipleLines(text, addStrikethroughUnicode)
      break
    default:
      formattedText = processMultipleLines(text, addStrikethroughHtml)
  }
  
  return formattedText
}
```
