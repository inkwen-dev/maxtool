# 空白和换行转换器技术设计文档

## 1. 概述

空白和换行转换器是一款帮助用户处理文本中空白字符和换行符的在线工具。用户可以输入或粘贴文本，选择要进行的操作（如删除所有空白、删除多余空白、统一换行符等），工具会自动处理文本并返回结果。

## 2. 功能设计

### 2.1 核心功能
- 删除所有空白字符
- 删除多余的空白字符（保留单个空格）
- 删除所有换行符
- 统一换行符（将\r\n转换为\n）
- 将换行符转换为空格
- 将多个换行符合并为一个
- 实时预览
- 复制功能

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `WhitespaceConverterTool`: 主组件，包含所有功能
  - `TextInput`: 文本输入组件
  - `OperationSelector`: 操作选择组件
  - `TextPreview`: 实时预览组件
  - `ActionButtons`: 操作按钮（转换、复制、重置）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 删除所有空白字符
const removeAllWhitespace = (text) => {
  return text.replace(/\s/g, '')
}

// 删除多余的空白字符（保留单个空格）
const removeExtraWhitespace = (text) => {
  return text.replace(/\s+/g, ' ').trim()
}

// 删除所有换行符
const removeAllNewlines = (text) => {
  return text.replace(/[\r\n]/g, '')
}

// 统一换行符（将\r\n转换为\n）
const unifyNewlines = (text) => {
  return text.replace(/\r\n/g, '\n')
}

// 将换行符转换为空格
const newlinesToSpaces = (text) => {
  return text.replace(/[\r\n]/g, ' ')
}

// 将多个换行符合并为一个
const mergeNewlines = (text) => {
  return text.replace(/[\r\n]+/g, '\n')
}

// 执行文本转换操作
const convertText = (text, operation) => {
  if (!text) return ''
  
  switch (operation) {
    case 'removeAllWhitespace':
      return removeAllWhitespace(text)
    case 'removeExtraWhitespace':
      return removeExtraWhitespace(text)
    case 'removeAllNewlines':
      return removeAllNewlines(text)
    case 'unifyNewlines':
      return unifyNewlines(text)
    case 'newlinesToSpaces':
      return newlinesToSpaces(text)
    case 'mergeNewlines':
      return mergeNewlines(text)
    default:
      return text
  }
}
```

### 3.3 组件复用
- `Button`: 通用按钮组件
- `Textarea`: 通用文本区域组件
- `Select`: 选择组件（操作类型）
- `UsageInstructions`: 使用说明组件

### 3.4 工具函数复用
- `copyToClipboard`: 复制功能
- `trackUsage`: 工具使用统计

## 4. 数据结构

```typescript
type WhitespaceOperation = 'removeAllWhitespace' | 'removeExtraWhitespace' | 'removeAllNewlines' | 'unifyNewlines' | 'newlinesToSpaces' | 'mergeNewlines'

interface WhitespaceConverterState {
  inputText: string
  outputText: string
  operation: WhitespaceOperation
  isProcessing: boolean
}
```
