# 打字练习工具技术设计文档

## 1. 概述

打字练习工具是一款帮助用户提高打字速度和准确率的在线工具。用户可以选择不同难度的文章进行练习，系统会实时统计打字速度、准确率等数据，并提供练习历史记录。

## 2. 功能设计

### 2.1 核心功能
- 随机文章生成或文章选择
- 实时打字速度统计（WPM - 每分钟单词数）
- 实时准确率统计
- 错误提示和纠正
- 练习历史记录
- 打字统计数据可视化

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 练习难度选择
- 打字声音反馈选项
- 使用说明和技巧

## 3. 技术设计

### 3.1 组件结构
- `TypingPractice`: 主组件，包含所有功能
  - `ArticleSelector`: 文章选择组件
  - `TypingArea`: 打字练习区域
  - `StatsDisplay`: 实时统计数据展示组件
  - `ErrorDisplay`: 错误提示组件
  - `HistoryChart`: 历史记录图表组件
  - `SettingsPanel`: 设置面板组件
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 打字速度计算
const calculateWPM = (correctChars, startTime, currentTime) => {
  if (!startTime) return 0
  
  const timeElapsed = (currentTime - startTime) / 1000 // 秒
  const minutes = timeElapsed / 60
  
  // 平均每个单词5个字符（英文标准）
  const words = correctChars / 5
  return Math.round(words / minutes)
}

// 准确率计算
const calculateAccuracy = (correctChars, totalTyped) => {
  if (totalTyped === 0) return 100
  return Math.round((correctChars / totalTyped) * 100)
}

// 打字状态管理
const handleKeyPress = (e, currentIndex, targetText, setCurrentIndex, setCorrectChars, setTotalTyped, setErrors) => {
  if (e.key.length !== 1) return // 忽略功能键
  
  setTotalTyped(prev => prev + 1)
  
  if (e.key === targetText[currentIndex]) {
    // 正确输入
    setCorrectChars(prev => prev + 1)
    setCurrentIndex(prev => prev + 1)
  } else {
    // 错误输入
    setErrors(prev => [...prev, {
      index: currentIndex,
      actual: e.key,
      expected: targetText[currentIndex],
      timestamp: Date.now()
    }])
  }
}
```

## 4. 数据结构

```typescript
interface TypingStats {
  wpm: number
  accuracy: number
  correctChars: number
  totalChars: number
  errors: number
  duration: number
  date: Date
}

interface TypingError {
  index: number
  actual: string
  expected: string
  timestamp: number
}

interface TypingArticle {
  id: string
  title: string
  content: string
  difficulty: 'easy' | 'medium' | 'hard'
  category: string
}

interface TypingPracticeState {
  article: TypingArticle
  currentIndex: number
  correctChars: number
  totalTyped: number
  errors: TypingError[]
  startTime: number | null
  endTime: number | null
  isPaused: boolean
  isComplete: boolean
  statsHistory: TypingStats[]
  settings: {
    soundEnabled: boolean
    difficulty: 'easy' | 'medium' | 'hard'
  }
}
```
