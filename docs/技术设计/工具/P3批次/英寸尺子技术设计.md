# 英寸尺子技术设计文档

## 1. 概述

英寸尺子是一款帮助用户在屏幕上测量物体尺寸的在线工具，使用英制单位（英寸）进行测量。用户可以在屏幕上放置需要测量的物体，然后使用尺子进行精确测量。

## 2. 功能设计

### 2.1 核心功能
- 显示英寸刻度的尺子
- 可调整尺子长度
- 显示精确的测量数值
- 支持水平和垂直方向
- 可拖动和缩放尺子
- 校准功能（确保测量准确性）

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例
- 测量结果复制功能

## 3. 技术设计

### 3.1 组件结构
- `InchRulerTool`: 主组件，包含所有功能

### 3.2 核心实现逻辑
```javascript
// 尺子状态管理
const [rulerState, setRulerState] = useState({
  length: 12, // 默认12英寸
  orientation: 'horizontal', // 默认水平方向
  scale: 1, // 缩放比例
  offsetX: 0, // X轴偏移
  offsetY: 0, // Y轴偏移
  calibration: 1, // 校准系数
  measurement: 0 // 当前测量值
})

// 计算像素到英寸的转换
const pixelsToInches = (pixels) => {
  return pixels / (96 * rulerState.calibration * rulerState.scale)
}

// 计算英寸到像素的转换
const inchesToPixels = (inches) => {
  return inches * 96 * rulerState.calibration * rulerState.scale
}

// 绘制尺子
const drawRuler = () => {
  const canvas = document.getElementById('inch-ruler-canvas')
  if (!canvas) return
  
  const ctx = canvas.getContext('2d')
  
  // 清除画布
  ctx.clearRect(0, 0, canvas.width, canvas.height)
  
  // 设置尺子尺寸
  if (rulerState.orientation === 'horizontal') {
    canvas.width = inchesToPixels(rulerState.length)
    canvas.height = 50
  } else {
    canvas.width = 50
    canvas.height = inchesToPixels(rulerState.length)
  }
  
  // 绘制刻度
  ctx.strokeStyle = '#000000'
  ctx.lineWidth = 1
  ctx.font = '10px Arial'
  ctx.textAlign = 'center'
  
  for (let i = 0; i <= rulerState.length; i++) {
    const pos = inchesToPixels(i)
    
    if (rulerState.orientation === 'horizontal') {
      // 绘制主刻度（1英寸）
      ctx.beginPath()
      ctx.moveTo(pos, 0)
      ctx.lineTo(pos, 30)
      ctx.stroke()
      
      // 绘制数字
      ctx.fillText(i.toString(), pos, 45)
      
      // 绘制子刻度（1/2英寸）
      const halfPos = inchesToPixels(i + 0.5)
      ctx.beginPath()
      ctx.moveTo(halfPos, 0)
      ctx.lineTo(halfPos, 20)
      ctx.stroke()
      
      // 绘制子刻度（1/4英寸）
      const quarterPos1 = inchesToPixels(i + 0.25)
      const quarterPos2 = inchesToPixels(i + 0.75)
      ctx.beginPath()
      ctx.moveTo(quarterPos1, 0)
      ctx.lineTo(quarterPos1, 15)
      ctx.moveTo(quarterPos2, 0)
      ctx.lineTo(quarterPos2, 15)
      ctx.stroke()
      
      // 绘制子刻度（1/8英寸）
      for (let j = 1; j < 8; j++) {
        const eighthPos = inchesToPixels(i + j / 8)
        if (j % 2 === 0) continue // 跳过已绘制的刻度
        
        ctx.beginPath()
        ctx.moveTo(eighthPos, 0)
        ctx.lineTo(eighthPos, 10)
        ctx.stroke()
      }
    } else {
      // 垂直方向绘制类似，省略...
    }
  }
}

  setRulerState(prev => ({ ...prev, calibration: newCalibration }))
```
