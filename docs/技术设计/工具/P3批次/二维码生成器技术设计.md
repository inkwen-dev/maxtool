# 二维码生成器技术设计文档

## 一、概述

本文档详细描述MaxTool 0.2版本中二维码生成器（QR Code Generator）工具的技术设计，包括功能设计、技术实现、组件结构和代码复用等方面。设计严格遵循项目规范，注重代码复用、组件化和性能优化。

## 二、功能设计

### 1. 核心功能

#### 基本二维码生成
- 将文本、URL或其他数据转换为二维码
- 支持自定义二维码大小
- 支持自定义二维码颜色（前景色和背景色）

#### 高级功能
- 支持在二维码中心添加Logo
- 支持生成不同纠错级别的二维码
- 支持下载生成的二维码（PNG格式）

### 2. 用户界面

#### 输入区域
- 文本输入框：用于输入要转换为二维码的数据
- URL验证：自动检测并验证URL格式

#### 配置选项
- 大小滑块：调整二维码尺寸（100px - 500px）
- 颜色选择器：设置二维码的前景色和背景色
- 纠错级别选择：低（L）、中（M）、高（Q）、最高（H）
- Logo上传：支持上传图片作为二维码中心Logo

#### 输出区域
- 二维码预览：实时显示生成的二维码
- 下载按钮：下载生成的二维码图片
- 复制按钮：复制二维码图片到剪贴板

#### 使用说明
- 提供简洁的使用步骤说明

## 三、技术设计

### 1. 技术选型

#### 核心库
- **qrcode.react**：用于生成二维码的React组件
- **html2canvas**：用于将DOM元素转换为图片（用于下载功能）

#### 浏览器API
- Canvas API：用于二维码生成和处理
- Clipboard API：用于复制二维码到剪贴板
- File API：用于Logo上传和处理

## 三、技术实现

### 1. 二维码生成实现

使用`qrcode.react`库生成二维码，该库提供了React组件形式的二维码生成功能，支持自定义大小、颜色和纠错级别等参数。

```tsx
<QRCodeSVG
  value={input}
  size={size}
  fgColor={foregroundColor}
  bgColor={backgroundColor}
  level={errorCorrectionLevel}
  includeMargin
/>
```

### 2. Logo添加实现

通过绝对定位将Logo图片叠加在二维码中心，使用CSS调整Logo的大小和样式。

```tsx
{logoUrl && (
  <div className="absolute top-1/2 left-1/2 transform -translate-x-1/2 -translate-y-1/2" style={{ width: size * 0.2, height: size * 0.2 }}>
    <img src={logoUrl} alt="Logo" className="w-full h-full object-contain bg-white rounded-full p-1" />
  </div>
)}
```

### 3. 下载功能实现

使用`html2canvas`库将二维码DOM元素转换为Canvas，然后使用Canvas API将其转换为PNG图片并下载。

```typescript
export function downloadQRCode(dataUrl: string, filename: string): void {
  const link = document.createElement('a')
  link.href = dataUrl
  link.download = filename
  document.body.appendChild(link)
  link.click()
  document.body.removeChild(link)
}
```

### 4. 复制功能实现

使用共享的`copyToClipboard`函数将二维码图片复制到剪贴板。

```typescript
const handleCopy = async () => {
  if (!qrcodeRef.current) return
  
  try {
    const canvas = await html2canvas(qrcodeRef.current)
    canvas.toBlob(async (blob) => {
      if (blob) {
        await copyToClipboard(blob)
        // 显示复制成功提示
      }
    })
  } catch (error) {
    console.error('复制失败:', error)
    // 显示复制失败提示
  }
}
```

## 四、性能优化

### 1. 实时生成优化

- 使用React的`useMemo`钩子缓存生成的二维码，避免不必要的重新渲染
- 限制输入变化的频率，使用防抖（debounce）技术减少生成次数

### 2. 资源优化

- 合理设置二维码的最大尺寸，避免占用过多内存
- 对上传的Logo图片进行压缩，限制最大尺寸
