# 代码格式化工具技术设计文档

## 1. 概述

代码格式化工具是一款帮助开发者格式化代码的在线工具。用户可以输入或上传代码，选择编程语言和格式化选项，工具会自动对代码进行格式化，使其符合一定的编码规范和风格。

## 2. 功能设计

### 2.1 核心功能
- 支持多种编程语言（JavaScript、Python、Java、C++等）
- 代码格式化（美化）
- 代码压缩（可选功能）
- 实时预览
- 复制和下载功能
- 代码高亮显示

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `CodeFormatterTool`: 主组件，包含所有功能
  - `CodeInput`: 代码输入组件（支持粘贴和上传）
  - `LanguageSelector`: 编程语言选择组件
  - `FormatSettings`: 格式化选项组件
  - `CodePreview`: 实时预览组件（带代码高亮）
  - `ActionButtons`: 操作按钮（格式化、压缩、复制、下载）
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 模拟代码格式化（实际实现会使用专业的代码格式化库）
const formatCode = (code, language, settings) => {
  try {
    // 根据不同语言进行格式化
    switch (language) {
      case 'javascript':
      case 'typescript':
        return formatJavaScript(code, settings)
      case 'python':
        return formatPython(code, settings)
      case 'java':
        return formatJava(code, settings)
      case 'cpp':
        return formatCpp(code, settings)
      case 'html':
        return formatHtml(code, settings)
      case 'css':
        return formatCss(code, settings)
      case 'json':
        return formatJson(code, settings)
      case 'xml':
        return formatXml(code, settings)
      default:
        return code // 如果不支持该语言，返回原始代码
    }
  } catch (error) {
    throw new Error('Failed to format code: ' + error.message)
  }
}

// JavaScript/TypeScript代码格式化（简化版）
const formatJavaScript = (code, settings) => {
  // 实际实现会使用Prettier等格式化库
  const { tabSize = 2, useTabs = false, semi = true, singleQuote = false } = settings
  
  // 这里只是简单地模拟格式化，实际项目中会使用更复杂的算法
  return code
    .replace(/\s+/g, ' ') // 替换多个空格为单个空格
    .replace(/; /g, ';\n') // 在分号后添加换行
    .replace(/{ /g, '{\n') // 在左大括号后添加换行
    .replace(/ }/g, '\n}') // 在右大括号前添加换行
    .split('\n')
    .map(line => line.trim())
    .filter(line => line)
    .join('\n')
}

// Python代码格式化（简化版）
const formatPython = (code, settings) => {
  // 实际实现会使用Black等格式化库
  const { tabSize = 4, useTabs = false } = settings
  
  // 这里只是简单地模拟格式化，实际项目中会使用更复杂的算法
  return code
    .replace(/\t/g, ' '.repeat(tabSize)) // 将制表符替换为空格
    .replace(/\s+/g, ' ') // 替换多个空格为单个空格
    .replace(/: /g, ':\n') // 在冒号后添加换行
    .split('\n')
    .map(line => line.trim())
    .filter(line => line)
    .join('\n')
}

// JSON代码格式化
const formatJson = (code, settings) => {
  try {
    const parsed = JSON.parse(code)
    return JSON.stringify(parsed, null, settings.tabSize || 2)
  } catch (error) {
    throw new Error('Invalid JSON format')
  }
}

// HTML代码格式化（简化版）
const formatHtml = (code, settings) => {
  // 实际实现会使用专门的HTML格式化库
  const { tabSize = 2 } = settings
  
  // 这里只是简单地模拟格式化
  return code
    .replace(/></g, '>\n<')
    .split('\n')
    .map(line => line.trim())
    .filter(line => line)
    .join('\n')
}

// 代码压缩（简化版）
const compressCode = (code, language) => {
  // 实际实现会使用专业的代码压缩库
  switch (language) {
    case 'javascript':
    case 'typescript':
      return code.replace(/\s+/g, '').replace(/;+/g, ';')
    case 'html':
      return code.replace(/\s+/g, ' ').replace(/<!--[\s\S]*?-->/g, '')
    case 'css':
      return code.replace(/\s+/g, '').replace(/;+/g, ';')
    case 'json':
      return JSON.stringify(JSON.parse(code))
    default:
      return code.replace(/\s+/g, ' ')
  }
}
```

## 4. 数据结构

```typescript
type ProgrammingLanguage = 'javascript' | 'typescript' | 'python' | 'java' | 'cpp' | 'html' | 'css' | 'json' | 'xml'

interface FormatSettings {
  tabSize: number
  useTabs: boolean
  semi: boolean
  singleQuote: boolean
  trailingComma: 'none' | 'es5' | 'all'
  bracketSpacing: boolean
}

interface CodeFormatterState {
  inputCode: string
  outputCode: string
  language: ProgrammingLanguage
  settings: FormatSettings
  isFormatting: boolean
  error: string | null
}
```
