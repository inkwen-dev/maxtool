# 网速测试工具技术设计文档

## 1. 概述

网速测试工具是一款帮助用户测量网络连接速度的在线工具。用户可以测试下载速度、上传速度和网络延迟，获取详细的网络性能报告。

## 2. 功能设计

### 2.1 核心功能
- 下载速度测试
- 上传速度测试
- 网络延迟测试（Ping）
- 实时测试进度显示
- 测试结果详细报告
- 测试历史记录

### 2.2 辅助功能
- 深色/浅色模式支持
- 响应式设计，适配不同设备
- 使用说明和示例

## 3. 技术设计

### 3.1 组件结构
- `SpeedTest`: 主组件，包含所有功能
  - `TestControls`: 测试控制组件（开始、停止、重新测试）
  - `TestProgress`: 测试进度显示组件
  - `DownloadTest`: 下载速度测试组件
  - `UploadTest`: 上传速度测试组件
  - `PingTest`: 网络延迟测试组件
  - `ResultsDisplay`: 测试结果显示组件
  - `TestHistory`: 测试历史记录组件
  - `UsageInstructions`: 使用说明组件

### 3.2 核心实现逻辑
```javascript
// 下载速度测试
const testDownloadSpeed = async (url, duration = 10000) => {
  const startTime = performance.now()
  let downloaded = 0
  let isRunning = true
  
  const controller = new AbortController()
  const signal = controller.signal
  
  try {
    // 创建一个大文件的下载请求
    const response = await fetch(url, {
      method: 'GET',
      signal,
      cache: 'no-store'
    })
    
    if (!response.ok) {
      throw new Error(`HTTP error! status: ${response.status}`)
    }
    
    const reader = response.body.getReader()
    const stream = new ReadableStream({
      async start(controller) {
        while (isRunning) {
          const { done, value } = await reader.read()
          if (done) {
            break
          }
          downloaded += value.length
          controller.enqueue(value)
          
          // 检查测试是否已超时
          if (performance.now() - startTime > duration) {
            isRunning = false
            break
          }
        }
        controller.close()
      }
    })
    
    // 读取流以完成下载
    await new Response(stream).text()
  } catch (error) {
    if (error.name !== 'AbortError') {
      throw error
    }
  } finally {
    if (isRunning) {
      controller.abort()
    }
  }
  
  const endTime = performance.now()
  const timeElapsed = endTime - startTime
  const speedBps = (downloaded * 8) / (timeElapsed / 1000)
  
  return {
    speed: speedBps,
    timeElapsed: timeElapsed,
    downloaded: downloaded
  }
}

// 上传速度测试
const testUploadSpeed = async (url, duration = 10000) => {
  const startTime = performance.now()
  let uploaded = 0
  let isRunning = true
  
  try {
    // 创建一个大文件进行上传
    const fileSize = 10 * 1024 * 1024 // 10MB
    const arrayBuffer = new ArrayBuffer(fileSize)
    const blob = new Blob([arrayBuffer], { type: 'application/octet-stream' })
    
    while (isRunning) {
      const uploadStartTime = performance.now()
      await fetch(url, {
        method: 'POST',
        body: blob,
        cache: 'no-store'
      })
      uploaded += fileSize
      
      // 检查测试是否已超时
      if (performance.now() - startTime > duration) {
        isRunning = false
        break
      }
    }
  } catch (error) {
    throw error
  }
  
  const endTime = performance.now()
  const timeElapsed = endTime - startTime
  const speedBps = (uploaded * 8) / (timeElapsed / 1000)
  
  return {
    speed: speedBps,
    timeElapsed: timeElapsed,
    uploaded: uploaded
  }
}

// Ping测试
const testPing = async (url) => {
  const startTime = performance.now()
  
  try {
    await fetch(url, {
      method: 'HEAD',
      cache: 'no-store'
    })
    
    const endTime = performance.now()
    return endTime - startTime
  } catch (error) {
    throw error
  }
}
```

## 4. 数据结构

```typescript
interface SpeedTestResult {
  id: string
  timestamp: Date
  downloadSpeed: number // bps
  uploadSpeed: number // bps
  ping: number // ms
  jitter: number // ms
  server: {
    name: string
    location: string
    distance: number // km
  }
}

interface SpeedTestState {
  isTesting: boolean
  currentTest: 'ping' | 'download' | 'upload' | null
  progress: number
  results: SpeedTestResult | null
  history: SpeedTestResult[]
  error: string | null
}
```
