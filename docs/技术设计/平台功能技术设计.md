# 平台功能技术设计文档（0.2版本）

## 一、概述

本文档详细描述MaxTool 0.2版本平台功能的技术设计，包括收藏功能、分享功能、使用历史和搜索功能增强等。设计严格遵循项目规范，注重代码复用、组件化和性能优化。

## 二、功能设计

### 1. 收藏功能

#### 功能描述
- 允许用户收藏常用工具
- 支持在个人收藏页面查看所有收藏的工具
- 支持从收藏中移除工具
- 收藏状态在工具卡片和工具详情页中显示

#### 用户界面
- 工具卡片上的收藏按钮（星形图标）
- 工具详情页的收藏按钮
- 导航栏中的"我的收藏"链接
- 个人收藏页面（/favorites）

### 2. 分享功能

#### 功能描述
- 支持将工具和结果分享到社交媒体
- 支持生成分享链接
- 支持复制分享链接到剪贴板

#### 用户界面
- 工具页面的分享按钮
- 分享选项弹出菜单（社交媒体图标和复制链接选项）

### 3. 使用历史

#### 功能描述
- 保存用户最近使用的工具和参数
- 支持查看使用历史
- 支持从历史记录中快速重新使用工具
- 支持清除历史记录

#### 用户界面
- 导航栏中的"使用历史"链接
- 使用历史页面（/history）
- 工具页面中的历史记录面板（可选）

### 4. 搜索功能增强

#### 功能描述
- 关键词高亮：搜索结果中高亮显示匹配关键词
- 搜索建议：根据输入提供工具搜索建议
- 分类过滤：支持按分类筛选搜索结果

#### 用户界面
- 搜索框（已存在，需增强）
- 搜索建议下拉菜单
- 搜索结果页面的分类过滤选项

### 5. 性能优化

#### 1. 数据缓存
- 收藏数据使用localStorage缓存
- 历史记录数据根据大小选择localStorage或IndexedDB
- 搜索结果使用内存缓存，减少重复搜索

#### 2. 懒加载
- 收藏和历史页面采用懒加载
- 搜索建议组件采用懒加载

#### 3. 代码分割
- 使用Next.js的代码分割功能
- 按路由分割代码，减少初始加载时间

## 四、数据库设计

### 1. 本地存储设计

#### 收藏数据
- **存储位置**：localStorage
- **存储格式**：JSON
- **键名**：`maxtool_favorites`
- **结构**：
  ```json
  {
    "tools": ["tool1", "tool2", "tool3"],
    "lastUpdated": 1634567890
  }
  ```

#### 使用历史数据
- **存储位置**：localStorage（小数据量）或IndexedDB（大数据量）
- **存储格式**：JSON
- **键名**：`maxtool_history`
- **结构**：
  ```json
  {
    "items": [
      {
        "id": "history1",
        "toolId": "random-number",
        "toolName": "随机数生成器",
        "params": {"min": "1", "max": "100"},
        "timestamp": 1634567890,
        "result": "42"
      }
    ],
    "maxItems": 50
  }
  ```

### 2. 后端数据库设计（可选，用于未来扩展）

#### 用户收藏表（users_favorites）
- **字段**：
  - `id`：主键，自增整数
  - `user_id`：用户ID（可扩展为用户系统）
  - `tool_id`：工具ID，外键
  - `created_at`：创建时间，timestamp
- **索引**：
  - `user_id` + `tool_id`（唯一索引）

#### 使用历史表（usage_history）
- **字段**：
  - `id`：主键，自增整数
  - `user_id`：用户ID（可扩展为用户系统）
  - `tool_id`：工具ID，外键
  - `params`：工具参数，JSONB
  - `result`：工具结果，TEXT
  - `created_at`：创建时间，timestamp
- **索引**：
  - `user_id`
  - `tool_id`
  - `created_at`

## 五、API设计

### 1. 前端API

#### 收藏API
```typescript
// 添加到收藏
await favoriteService.addToFavorites(toolId);

// 从收藏中移除
await favoriteService.removeFromFavorites(toolId);

// 检查是否收藏
const isFavorite = await favoriteService.isFavorite(toolId);

// 获取所有收藏
const favorites = await favoriteService.getFavorites();
```

#### 分享API
```typescript
// 生成分享链接
const shareUrl = shareService.generateShareUrl(toolId, params);

// 分享到社交媒体
await shareService.shareToSocialMedia('twitter', shareUrl);

// 复制分享链接
await shareService.copyShareUrl(shareUrl);
```

#### 历史记录API
```typescript
// 添加到历史记录
const historyId = await historyService.addToHistory(historyItem);

// 获取历史记录
const history = await historyService.getHistory(20);

// 清除历史记录
await historyService.clearHistory();

// 删除历史记录项
await historyService.deleteHistoryItem(historyId);
```

#### 搜索API
```typescript
// 搜索工具
const results = await enhancedSearchService.search(query, category);

// 获取搜索建议
const suggestions = await enhancedSearchService.getSearchSuggestions(query);
```

### 2. 后端API（可选，用于未来扩展）

#### 收藏API
- `GET /api/favorites`：获取用户收藏
- `POST /api/favorites/:toolId`：添加到收藏
- `DELETE /api/favorites/:toolId`：从收藏中移除

#### 历史记录API
- `GET /api/history`：获取用户历史记录
- `POST /api/history`：添加到历史记录
- `DELETE /api/history`：清除历史记录
- `DELETE /api/history/:id`：删除历史记录项

## 八、风险与挑战

### 1. 数据存储限制
- **风险**：localStorage的存储容量限制（约5MB）
- **解决方案**：当数据量超过阈值时，迁移到IndexedDB

### 2. 兼容性问题
- **风险**：某些浏览器可能不支持某些API（如Web Share API）
- **解决方案**：提供降级方案，如复制链接功能

### 3. 性能问题
- **风险**：大量历史记录可能影响性能
- **解决方案**：实现分页加载和数据清理策略
