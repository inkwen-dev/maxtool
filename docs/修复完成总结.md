## 🎨 新增颜色变量使用指南

### Success（成功）
```tsx
// 背景
<div className="bg-success-bg">Success background</div>

// 文字
<p className="text-success-text">Success text</p>

// 强调色
<button className="bg-success text-white">Success button</button>
```

### Error（错误）
```tsx
// 背景
<div className="bg-error-bg">Error background</div>

// 文字
<p className="text-error-text">Error text</p>

// 强调色
<button className="bg-error text-white">Error button</button>
```

### Warning（警告）
```tsx
// 背景
<div className="bg-warning-bg">Warning background</div>

// 文字
<p className="text-warning-text">Warning text</p>

// 强调色
<button className="bg-warning text-white">Warning button</button>
```

### Info（信息）
```tsx
// 背景
<div className="bg-info-bg">Info background</div>

// 文字
<p className="text-info-text">Info text</p>

// 强调色
<button className="bg-info text-white">Info button</button>
```
