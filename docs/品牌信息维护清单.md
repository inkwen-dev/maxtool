# 品牌信息维护清单

本文档列出了项目中所有涉及品牌信息的页面和位置，方便统一维护和更新。

> ⚠️ **重要提示**：品牌信息的核心配置在 `lib/metadata.ts` 中的 `siteConfig`，建议优先修改该文件，其他位置会自动使用统一配置。
---
## 📋 品牌信息分类

### 1. 网站名称（Site Name）

#### 位置 1：核心配置（推荐优先修改）
**文件：** `lib/metadata.ts`  
**配置项：** `siteConfig.name`  
**当前值：** `'MaxTool'`  
**说明：** 这是品牌名称的统一数据源，所有页面都会使用此配置。

#### 位置 2：全局布局 - SEO 标题
**文件：** `app/layout.tsx`  
**说明：** 使用 `generateBaseMetadata()` 函数，自动从 `siteConfig` 读取品牌名称。

#### 位置 3：导航栏 Logo
**文件：** `components/shared/Navigation.tsx`  
**内容：**
```tsx
<span className="text-2xl font-bold text-accent">MaxTool</span>
```

#### 位置 4：页脚品牌名称
**文件：** `components/shared/Footer.tsx`  
**内容：**
```tsx
<h3 className="font-semibold text-text-primary mb-4">MaxTool</h3>
```

#### 位置 5：首页标题
**文件：** `app/page.tsx`  
**内容：**
```tsx
<h1 className="text-5xl font-bold text-text-primary mb-4">
  MaxTool
</h1>
```

#### 位置 6：各页面 SEO 标题
所有页面使用 `generateBaseMetadata()` 或 `generateToolMetadata()` 函数，自动生成包含品牌名称的标题：
- `app/about/page.tsx`：`About - MaxTool`
- `app/contact/page.tsx`：`Contact - MaxTool`
- `app/privacy/page.tsx`：`Privacy Policy - MaxTool`
- `app/terms/page.tsx`：`Terms of Service - MaxTool`
- 所有工具页面：`{工具名称} - MaxTool`

## ⚠️ 注意事项

1. **核心配置优先**：优先修改 `lib/metadata.ts` 中的 `siteConfig`，这是品牌信息的统一数据源
2. **一致性**：确保所有位置的网站名称保持一致（当前品牌名称：MaxTool）
3. **联系方式**：`contact@example.com` 需要替换为真实邮箱
4. **版权年份**：Footer 中的年份是动态的（使用 `new Date().getFullYear()`），会自动更新
5. **SEO 优化**：各页面的 metadata 使用 `generateBaseMetadata()` 自动生成，确保SEO一致性
6. **法律合规**：隐私政策和服务条款需要根据实际业务更新
7. **Metadata 函数**：所有页面使用统一的 metadata 生成函数，确保品牌信息一致性

## 💡 维护建议

### 优先修改核心配置

**推荐方式：** 优先修改 `lib/metadata.ts` 中的 `siteConfig`，这是品牌信息的统一数据源。

**优势：**
- 一次修改，全局生效
- 避免遗漏某些位置
- 保持品牌信息一致性

**需要单独修改的位置：**
- 导航栏Logo文字（`components/shared/Navigation.tsx`）
- 页脚品牌名称（`components/shared/Footer.tsx`）
- 首页H1标题（`app/page.tsx`）
- 联系邮箱（`app/contact/page.tsx`）

### 品牌信息更新流程

1. **修改核心配置**：更新 `lib/metadata.ts` 中的 `siteConfig`
2. **更新UI显示**：修改导航栏、页脚、首页的显示文字
3. **更新联系信息**：修改联系页面的邮箱地址
4. **检查一致性**：确保所有位置的品牌名称一致
5. **测试验证**：检查所有页面的SEO metadata是否正确生成
