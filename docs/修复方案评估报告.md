## 三、修复方案详细设计

### 3.1 语义化颜色变量设计

**设计原则：**
1. ✅ 遵循项目现有的命名规范（`--color-*`）
2. ✅ 支持 Light/Dark 模式
3. ✅ 易于扩展新主题
4. ✅ 符合 WCAG 可访问性标准

**具体实现：**

```css
@theme {
  /* 基础颜色（已存在） */
  --color-bg-primary: #ffffff;
  --color-bg-card: #ffffff;
  --color-text-primary: #171717;
  --color-accent: #3b82f6;
  
  /* 新增：语义化颜色 */
  --color-success: #10b981;        /* green-500 */
  --color-success-bg: #d1fae5;      /* green-100 */
  --color-success-text: #065f46;   /* green-800 */
  
  --color-error: #ef4444;           /* red-500 */
  --color-error-bg: #fee2e2;         /* red-100 */
  --color-error-text: #991b1b;      /* red-800 */
  
  --color-warning: #f59e0b;         /* amber-500 */
  --color-warning-bg: #fef3c7;      /* amber-100 */
  --color-warning-text: #78350f;    /* amber-800 */
  
  --color-info: #3b82f6;            /* blue-500 */
  --color-info-bg: #dbeafe;         /* blue-100 */
  --color-info-text: #1e40af;       /* blue-800 */
}

@layer theme {
  .dark {
    /* 基础颜色（已存在） */
    --color-bg-primary: #0f172a;
    --color-bg-card: #1e293b;
    --color-text-primary: #f8fafc;
    --color-accent: #3b82f6;
    
    /* 新增：语义化颜色（Dark 模式） */
    --color-success: #10b981;        /* green-500 */
    --color-success-bg: #064e3b;     /* green-900 */
    --color-success-text: #6ee7b7;   /* green-300 */
    
    --color-error: #ef4444;           /* red-500 */
    --color-error-bg: #7f1d1d;        /* red-900 */
    --color-error-text: #fca5a5;      /* red-300 */
    
    --color-warning: #f59e0b;         /* amber-500 */
    --color-warning-bg: #78350f;      /* amber-900 */
    --color-warning-text: #fcd34d;    /* amber-300 */
    
    --color-info: #3b82f6;            /* blue-500 */
    --color-info-bg: #1e3a8a;         /* blue-900 */
    --color-info-text: #93c5fd;       /* blue-300 */
  }
}
```

**使用示例：**

```tsx
// ✅ 正确：使用语义化颜色变量
<div className="bg-error text-error-text">
  错误消息
</div>

// ✅ 正确：使用主题变量
<div className="bg-success-bg border-success">
  成功提示
</div>

// ❌ 错误：硬编码颜色（不支持 dark 模式）
<div className="bg-red-500 text-red-800">
  错误消息
</div>
```
